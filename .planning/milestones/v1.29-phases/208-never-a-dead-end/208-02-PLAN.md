<objective>
Close the two field-reported dead ends inside the check that make an honest phase unable to pass:
a per-task verdict computed from a phase-wide flag (WINDOWS.md row 50), and a verification command
silently dropped because its first word is `cd` (WINDOWS.md row 51).

Purpose: both were reported from a real external project running 1.0.88 on 2026-09-22. The first
sends the owner and the automatic repair worker after a phantom second defect; the second tells
the owner no command was configured when one plainly was, and the owner then has nothing to act on.

Output: a per-task verdict bound to that task's own criteria, a gate that names the causal
criterion once, `cd <dir> &&` verification commands that actually run, and a loud, named refusal
for a line Aether genuinely cannot read.
</objective>
