carries the one command that gets past it, rendered identically on both exit lanes, recorded in a
local refusal log, and routed to a one-command report bundle the owner can send instead of letting
a chat patch Aether's source.

journey both dead-ended on refusals that named no way forward, and a chat then narrated around
them. This slice makes "how do I get past this" a required field rather than prose discipline.
