<objective>
Produce the sorted refusal list the phase goal names: one checked-in table classifying every
registered refusal as protecting against losing work or not, the ones that do not converted into
warnings that carry on, and an honest, shrink-only count of what is not yet typed.

Purpose: "every place the program refuses is listed and sorted" is only true if the list is
mechanically complete or its incompleteness is counted. There are hundreds of error returns in the
lifecycle files; this plan types the ones an owner actually hits, proves each one behaves the way
the table says, and records the remainder as a number that can only go down.

Output: the classification rule, the filled register, the converted warnings, the recorded floor,
and a test that fails when the program's behaviour and the table disagree.
</objective>

    - No row is exercised by both behaviours.
    - A row nothing can drive is reported as a row with no behavioural coverage, not silently skipped.

names a driver: a small closure that puts the program in the state that refusal fires from, reusing
