<objective>
Make the program carry out the recovery itself when nobody is there to answer, on the one path that
has stopped every real rehearsal so far: an existing survey found by `aether colonize`.

Purpose: three real, paid walks have now stopped at the same step for three different reasons, the
last of them being a chat that read a correct, unambiguous instruction and asked a question anyway.
The owner's ruling (D-03) is that an instruction is not a mechanism — when Aether can see that
nobody is present, Aether does the recovery rather than asking a chat to. This plan builds exactly
that, for exactly that refusal, and changes nothing about what happens when a person is there.

Output: one shared decision, wired into both colonize lanes, with the guards that keep it honest —
attended behaviour untouched, one decision not two, and only a refusal that has declared itself
recoverable ever recovered from.
</objective>
