Aether practice project, one lifecycle menu command runs through a real chat with hooks
loaded, the harness asserts on what actually happened (a menu-command tag, a Bash tool

architectural dead end costs one commit instead of ten.

library plus its offline tests, and the `journey` eval gate wired into the manifest and
the Makefile.

`claude` flags, the session-id chaining, the assertion surfaces and the gate's home were all
verified there against this machine's own tooling, the live official documentation and this
repository's own source. Read it before starting; do not re-derive it.
