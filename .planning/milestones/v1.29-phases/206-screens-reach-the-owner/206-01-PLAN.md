<objective>
Build the direct route: when a chat runs a command that draws one of Aether's screens, the
program hands that screen to Claude Code as a message shown straight to the owner, with no
model turn spent and nothing for the chat to paste. Then make the existing finish-check
backstop compose honestly with it, so a screen that already arrived whole is not demanded
twice, and a screen that only partly arrived still is.

Purpose: the owner's own words on 2026-09-21 were that he keeps going in circles. Half the
reason is that Aether draws a truthful screen and the chat then summarises it away. The
backstop shipped in 1.0.88 catches that after the fact, at the cost of a model turn and a
told-off reply. This makes the screen arrive the first time.

Output: one new hidden command, one shared decision function both routes call, real captured
fixtures, the shipped settings that install it, and a CLAUDE.md section whose every claim
names its locking test.
</objective>
