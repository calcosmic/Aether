<objective>
Extract source anchors from the cleaned survey output and wire them through to the planner. Source anchors are the top 50 non-dependency, non-test source files sorted by path depth -- the concrete file paths that make plans specific to the repo instead of generic.

Purpose: The planner currently gets languages, frameworks, and directories but not the actual source file paths. With anchors, it can say "modify cmd/codex_colonize.go" instead of "modify the colonize module". This is the data pipeline that makes grounded planning possible.

Output: extractSourceAnchors function in codex_colonize.go, SourceAnchors field on codexWorkspaceFacts and codexSurveyContext, anchors.json written during survey, anchors read during plan context loading.
</objective>
