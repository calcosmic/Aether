## Milestone Summary

**Key Decisions:**

- "Compiled code may execute behaviour, but editable assets must define behaviour." — hard rule documented in ARCHITECTURE_BOUNDARY.md
- MATCH + DEGRADED count as verifiable; GAP + INTENTIONALLY_CHANGED do not — explicit parity checklist counting method
- Orchestrator owns STATE.md and ROADMAP.md updates, not parallel executors

**Issues Resolved:**

- Go runtime was the "whole organism" — all behaviour embedded in compiled code
- No editable colony brain — users could not modify agent personalities, phase rituals, or playbooks without recompiling
- No TypeScript control plane — orchestration was split between Go and wrapper markdown with no unified runtime
- No observable event stream — behaviour was hidden in prose logs

**Issues Deferred:**

- Full adapter implementations for Codex and OpenCode (stubs only)
- Vector/memory backend (file-backed is sufficient)
- Web UI / TUI cockpit (terminal + NDJSON is sufficient)
- Federation (deferred until local loop is stable)
- Multi-provider routing with fallback (policy schema only)

**Technical Debt Incurred:**

- `executePlan.test.ts` test isolation — create parent directory before writing COLONY_STATE.json
- Phases 152-156 missing VERIFICATION.md (completed before verification workflow was standard)
- Nyquist validation frontmatter not updated for most phases
