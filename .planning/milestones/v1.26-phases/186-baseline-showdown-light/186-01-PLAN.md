<objective>
Prove the harness's single biggest practical risk is survivable before anything else is built:
a clean HOME can boot, authenticate, and complete one trivial task in BOTH Aether and GSD.

Purpose: CONTEXT.md locks this as the first milestone — "Nothing else is built until this
passes." The three named risks are macOS Keychain authentication for the `claude` CLI under an
overridden `HOME`, `getpwuid` home resolution disagreeing with `$HOME`, and GSD's install being
a plain file copy with no installer. If any of these is fatal, the entire 12-run design must
change, and it is cheaper to learn that now than after the task specs and acceptance scripts
are written.

Output: `bench/lib/hermetic-home.sh` (shared isolated-HOME setup), `bench/lib/gsd-install.sh`
(GSD file-copy install), `bench/smoke-hermetic.sh` (the gate), `bench/README.md` (first
section: what the smoke proves and its prerequisites).
</objective>

Export one function `hermetic_home_setup LANE_NAME BASE_DIR` that:
- Pins `GOPATH`, `GOMODCACHE` and `GOCACHE` from `go env` BEFORE any HOME override, so the

  document why in a comment as smoke-daily-driver.sh does).

  `$HOME/.claude` and `$HOME/.config`.
- Writes an identical minimal global `$HOME/.claude/CLAUDE.md` for every lane — the same bytes

  instruction file with no mention of Aether, GSD, colonies, phases, or benchmarks.
- Records `HOME` and the lane name on stdout as `hermetic-home lane=<lane> home=<path>`.

Export a second function `hermetic_home_probe` that detects the `getpwuid` divergence risk: it
runs `node -e` (node is already a required tool) to print `os.homedir()` and compares it to
`$HOME`. If they disagree, print a loud warning naming both values and set
`HERMETIC_HOME_GETPWUID_DIVERGES=1` — do not exit; the smoke's gates decide whether the
divergence is fatal.

the install exits non-zero.

Create `bench/lib/gsd-install.sh` as a sourceable library exporting `gsd_install_into_home
SOURCE_HOME`. GSD has no installer — it is a file copy from an existing installation. The
function must:
- Require `SOURCE_HOME` (default `$REAL_HOME`, captured by the caller before the HOME override)
  to contain `.claude/get-shit-done/VERSION`, failing with a named message otherwise.
- Copy `$SOURCE_HOME/.claude/get-shit-done` recursively to `$HOME/.claude/get-shit-done`.
- Copy `$SOURCE_HOME/.claude/agents/gsd-*.md` into `$HOME/.claude/agents/`.
- Copy `$SOURCE_HOME/.claude/skills/gsd-*` recursively into `$HOME/.claude/skills/`.
- Resolve the `gsd-sdk` executable via `command -v gsd-sdk`, and if found, prepend its
  containing directory to `PATH` for the lane (gsd-sdk is a node script on PATH, not inside
  `$HOME/.claude`, so it is made reachable rather than copied).
- Print `gsd-install version=<contents of the copied VERSION file> agents=<count> skills=<count>`
  so the smoke can assert non-zero counts.
- Fail with a named message if the copied agents count is 0 or the copied skills count is 0.

Both libs follow the repo convention `ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"`
for locating the Aether repo root regardless of the caller's working directory.

Create `bench/smoke-hermetic.sh`, executable (`chmod +x`), following scripts/smoke-daily-driver.sh's
whole-file structure: doc header comment block stating what it proves and its exit behaviour,
`set -euo pipefail`, `ROOT="$(cd "$(dirname "$0")/.." && pwd)"`, `WORK="$(mktemp -d)"`,
`trap 'chmod -R u+w "$WORK" 2>/dev/null || true; rm -rf "$WORK"' EXIT`, and a required-tool
preflight loop over `go node npm jq git claude` (capture `REAL_HOME="$HOME"` before any override,
and resolve `gsd-sdk`'s directory before any override too).

Numbered gates, each using `step` then `fail`-on-violation:

Gate 1 — Aether lane boots in a clean HOME. Build the binary once with
`go build -o "$WORK/aether" ./cmd/aether`. Call `hermetic_home_setup aether "$WORK"`, then
`hermetic_home_probe`, then `hermetic_home_install_aether "$ROOT" "$WORK/aether"`. Assert
`"$WORK/aether" version` exits 0 and its output is non-empty, and that
`$HOME/.aether/system` exists. Fail naming the missing artifact if not.

Gate 2 — Aether completes one trivial task in the clean HOME. Create a throwaway git repo at
`$WORK/aether-repo` (`git init -q`, one committed README). From it, run `aether init` with a
trivial goal, then `aether build 1 --print-brief`. Assert the print-brief exit code is 0 and
its stdout is non-empty. This is the "completes one trivial task" proof for the Aether lane
without spending model tokens — it exercises install, colony state, and brief composition end
to end in the isolated HOME. If `aether init` requires an argument shape this repo's CLI does
not accept, capture stdout+stderr to `$WORK/aether-init.out`, print its first 10 lines to
stderr, and `fail` with the real reason — never swallow it.

Gate 3 — GSD lane boots in a clean HOME. Call `hermetic_home_setup gsd "$WORK"` (a SECOND,
sibling isolated HOME — the two lanes must never share a HOME), then
`gsd_install_into_home "$REAL_HOME"`. Assert `$HOME/.claude/get-shit-done/VERSION` exists and
is non-empty, that `ls "$HOME"/.claude/agents/gsd-*.md | wc -l` is at least 20, and that
`ls -d "$HOME"/.claude/skills/gsd-* | wc -l` is at least 20. Assert `gsd-sdk --version` exits 0
under the isolated HOME and prints a version string.

Gate 4 — the Claude CLI authenticates under an overridden HOME, in BOTH isolated HOMEs. This is
the macOS Keychain risk and the whole reason this plan exists. For each lane HOME, run the
`claude` CLI in non-interactive one-shot mode with a trivial prompt and a short model, capturing
stdout+stderr to `$WORK/<lane>-auth.out` and its exit status with the `set +e` / capture / `set -e`
pattern. On non-zero exit, print the first 10 lines of the capture to stderr and `fail` with
"lane <lane>: claude CLI did not authenticate under an overridden HOME — see $WORK/<lane>-auth.out".
On zero exit, assert a session transcript now exists under that lane's own HOME by globbing
`"$HOME"/.claude/projects/*/*.jsonl` and requiring at least one match — this simultaneously
proves authentication worked AND that harness-side token measurement will have a file to read.
Print the matched transcript path.

Gate 5 — the two lanes are filesystem-isolated. Assert the two lane HOME paths differ, that the
Aether lane's HOME contains no `get-shit-done` directory, and that the GSD lane's HOME contains
no `.aether/system` directory. Any crossover fails.

Final line on success: `HERMETIC SMOKE PASS: both systems boot, authenticate and complete a
trivial task in clean HOMEs`.

Do NOT use the skip-loudly pattern for the `claude` CLI or for GSD — both are mandatory for this
gate. Skipping either would make the gate report a pass it did not earn. The preflight tool loop
is the correct place to refuse to run at all.
  </action>
