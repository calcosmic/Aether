<objective>
Capture the one thing only the platform can tell us — where this session's transcript lives — and
lock the refusal of any token figure an orchestrating LLM tries to assert.

Purpose: SPEND-02's whole honesty argument (D-06) rests on the Go runtime reading a real artifact
itself. The `PreToolUse` hook already fires on every `Agent`/`Task` dispatch and already carries
`transcript_path`; today the field is thrown away because `claudeHookInput` does not declare it.
The other half of the same argument is negative: a wrapper must not be able to hand us a number.

Output: `claudeHookInput` gains `TranscriptPath`, a new fail-soft capture writes it to
`.aether/data/spend/session.json`, and a named test proves a completion packet carrying `usage`
is rejected.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Claude Code hook stdin → `claudeHookInput` | Platform-generated JSON; normally trustworthy but is still an untrusted file-read target |
| wrapper completion JSON → completion packet | Composed by the orchestrating LLM; nothing it states about cost may be believed |
| `.aether/data/spend/` → worker Write tool | Colony state; the hook's protected-path rule must keep denying writes here |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-174-01 | Tampering | `claudeHookInput.TranscriptPath` | mitigate | `validateSpendTranscriptPath` rejects null bytes and relative paths, resolves symlinks on both root and candidate, and requires containment under `$HOME/.claude/projects` decided by `filepath.Rel`, never `strings.HasPrefix`. Asserted by `TestSpendSessionCaptureRefusesPathOutsideClaudeProjects` |
| T-174-04 | Tampering | completion packet `usage` key | mitigate | No `usage` field is declared on `codexExternalBuildWorkerResult`, so the reflected schema rejects it with a named `additionalProperties` violation. Asserted by `TestCompletionPacketRefusesAssertedWorkerUsage` |
| T-174-09 | Denial of service | `recordSpendSessionFromHook` | mitigate | Every error path returns silently and the function has no return value, so a full disk or unwritable store cannot turn into a denied dispatch. Asserted by `TestSpendSessionCaptureFailureDoesNotAffectHookDecision` |
| T-174-10 | Tampering | `.aether/data/spend/` | mitigate | The directory is deliberately absent from `sanctionedDataWritePrefixes`, so `protectedHookWriteReason` keeps blocking any worker Write/Edit aimed at it. Asserted by an acceptance-criteria grep |
| T-174-11 | Information disclosure | `spend/session.json` | accept | The record holds a local filesystem path, a session UUID and a working directory — all already present in colony state and in the operator's own shell history |
</threat_model>
