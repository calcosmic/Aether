<objective>
Build the NDJSON event stream stubs in the Go runtime. These stubs let the Go side emit and consume structured events in the same format as the TypeScript control plane. The Go runtime will eventually write to `.aether/events/current.ndjson` during colony operations.

Purpose: The event stream is the shared observable truth. Go must be able to emit structured events that TypeScript can read, and vice versa. Clean interfaces matter more than implementation depth.
Output: Go event types, writer, reader, stream initialization, and tests.
</objective>

<tasks>

### Task 1: Go Event Types

Create `cmd/event_types.go` with:

- `EventType` type (string-based enum) with constants: `PhaseStart`, `AgentSelected`, `TaskPlanned`, `WorkerSpawned`, `ToolCall`, `VerificationResult`, `MemoryUpdate`, `RunSeal`, `Custom`
- `EventLine` struct with `Type EventType`, `Timestamp string`, `Payload EventPayload`
- `EventPayload` as a map[string]interface{} for flexibility (mirrors TS discriminated union)
- `NewEventLine(eventType, payload)` constructor that injects the current ISO timestamp
- JSON marshaling/unmarshaling methods if needed

### Task 2: Go Event Writer

Create `cmd/event_writer.go` with:

- `WriteEvent(streamPath string, eventLine EventLine) error` — writes a JSON line to a file (uses os.OpenFile with O_APPEND, or writes to an in-memory buffer in stub mode)
- `CreateEventStream(streamPath string) (*EventStream, error)` — returns a struct with `Write(eventLine) error` and `Close() error` methods
- Thread-safe writes using a mutex

### Task 3: Go Event Reader

Create `cmd/event_reader.go` with:

- `ReadEvents(streamPath string) ([]EventLine, error)` — reads all events from a file
- `TailEvents(streamPath string) (<-chan EventLine, error)` — returns a channel that yields new events as they arrive (uses fsnotify or polling in stub mode)
- Proper JSON line parsing (handles newline-delimited JSON)

### Task 4: Event Stream Initialization

Create `cmd/event_stream.go` with:

- `InitEventStream() (string, error)` — creates `.aether/events/` directory and returns the path to `current.ndjson`
- `GetEventStreamPath() string` — returns the default event stream path
- Integration with existing cmd/ commands to demonstrate event emission (add event calls to one or two existing commands as proof of concept)

### Task 5: Tests

Create `cmd/events_test.go`:

- Test `NewEventLine` produces correct shape with timestamp
- Test `WriteEvent` appends to file correctly
- Test `ReadEvents` returns parsed events
- Test `TailEvents` yields new events
- Test round-trip: write then read returns the same events
- Test NDJSON format (one JSON object per line, no trailing commas)
- Test concurrent writes (thread safety)

Commit each task individually.

</tasks>
