    Review the automated scan output and classify each (file, symbol) pair into one of these categories:
    - **KEEP_IN_GO**: Pure runtime spine logic (state mutation, file locking, CLI parsing, event bus plumbing, install/update/publish)
    - **MOVE_TO_TS**: Orchestration logic that should live in TypeScript control plane (agent selection, phase sequencing, prompt assembly)
    - **MOVE_TO_YAML**: Structured definitions that fit YAML (agent specs, phase specs, policy rules)
    - **MOVE_TO_MARKDOWN**: Narrative/ceremony content that fits Markdown (prompt text, playbook content, ceremony templates)
    - **MOVE_TO_JSON**: Machine-readable config or state schemas (event schemas, memory schemas)
    - **DELETE**: Dead code or behaviour already superseded
