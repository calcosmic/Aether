  <action>
    Create control-ts/src/orchestrator/executePlan.ts with one exported function:
    - executePlan(sequence: string[], options?: { inputs?: Record<string, Record<string, unknown>>; maxRetries?: number }): Promise<PlanResult>

    PlanResult type:
    ```typescript
    export interface PlanResult {
      status: "completed" | "failed" | "partial";
      results: PhaseResult[];
      events: ColonyEvent[];
      startedAt: string;
      completedAt: string;
    }
    ```

    Implementation:
    1. Emit "plan:start" event to .aether/events/current.ndjson with payload { sequence, startedAt: new Date().toISOString() }.
    2. Read current colony state via readColonyState().
    3. Update colony state to { ...state, state: "RUNNING" } via updateColonyState().
    4. Initialize results: PhaseResult[] = [], events: ColonyEvent[] = [plan:start event].
    5. For each phaseId in sequence (in order):
       a. Load the phase definition via loadPhaseById(phaseId). If not found, create a PhaseResult with status "failed", error "Phase not found", append to results, and break (treat as block).
       b. Determine inputs: options.inputs?.[phaseId] || {}.
       c. Call runPhase(phaseId, inputs) to get PhaseResult.
       d. Append PhaseResult to results, append its events to the events array.
       e. If PhaseResult.status === "failed":
          - If phase.failure_policy === "block": break loop.
          - If phase.failure_policy === "skip": continue to next phase.
          - If phase.failure_policy === "retry": retry once (call runPhase again). If second call also fails, treat as block (break loop).
          - If phase.failure_policy === "escalate": break loop (escalation is a stop condition for now; Phase 157 may add escalation adapter).
       f. If PhaseResult.status === "completed": update colony state current_phase to the index + 1.
    6. After loop, determine PlanResult.status:
       - If all results completed: "completed"
       - If some completed and some failed with skip: "partial"
       - If any failed with block/escalate/retry-exhausted: "failed"
    7. Update colony state: if status === "completed", set state to "COMPLETED"; else keep state as-is or set to "FAILED".
    8. Emit "plan:complete" event with payload { status, completedAt: new Date().toISOString(), phaseCount: results.length }.
    9. Return PlanResult.

    Use loadPhaseById from ../phases/loadPhases.js. Use runPhase from ./runPhase.js. Use readColonyState / updateColonyState from ../memory/store.js. Use EventSchema.parse for event validation. Use appendFileSync for NDJSON writes. Use projectRoot for path resolution.

    Write tests in control-ts/tests/orchestrator/executePlan.test.ts. Use real colony/ phases for the "init", "plan", "build" sequence. Mock runPhase for failure-policy tests (inject a mock runPhase that returns failed status on specific phase IDs). Verify NDJSON events by reading the events file. Verify colony state updates by reading COLONY_STATE.json before and after.
