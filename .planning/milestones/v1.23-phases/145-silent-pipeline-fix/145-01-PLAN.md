## Target Pattern Categories

### Category A: Data-persistence calls — REMOVE suppression entirely
These write to colony state and must fail visibly:
- `aether memory-capture`
- `aether midden-write`
- `aether pheromone-write`
- `aether spawn-log`
- `aether activity-log`
- `aether context-update`
- `aether grave-add`
- `aether flag-add`
- `aether learning-check-promotion`
- `aether learning-approve-proposals`
- `aether learning-promote-auto`
- `aether learning-extract-fallback`
- `aether instinct-promote`
- `aether hive-promote`
- `aether queen-promote`
- `aether event-bus-publish`
- `aether trust-score-compute`

### Category B: Read-only / probe fallbacks — KEEP suppression
These are safe to suppress (no data loss):
- `curl ... 2>/dev/null`
- `grep ... 2>/dev/null`
- `stat ... 2>/dev/null`
- `ls ... 2>/dev/null`
- `git rev-parse ... 2>/dev/null`
- `wc -l ... 2>/dev/null`
- `find ... 2>/dev/null`

### Category C: State-mutate guard calls — KEEP `2>/dev/null` (not `|| true`)
These already use `2>/dev/null` without `|| true`; leave unchanged:
- `aether state-mutate --guard ... 2>/dev/null`
- `aether state-mutate --revert ... 2>/dev/null`

### Category D: jq reads with fallback defaults — KEEP suppression
These read state and provide sensible defaults; no data loss:
- `jq ... 2>/dev/null || echo "..."`
