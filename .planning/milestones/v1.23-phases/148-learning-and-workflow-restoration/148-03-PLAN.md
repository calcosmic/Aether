# Plan 148-03: Worker Context Audit and Restoration

**Objective:** Verify that continue, plan, and colonize worker dispatches include the same context (skills, pheromones, handoffs, survey data) as build dispatches. Fix any gaps found.

## must_haves

- All worker dispatches (build, continue, plan, colonize) attach pheromone signals
- All worker dispatches attach matched skills
- All worker dispatches attach handoff sections when prior worker handoffs exist
- Survey data (if available) is included in all dispatches
- Differences between workflows are documented, not silently inconsistent
