# Plan 151-01: Full Lifecycle Smoke Test in Downstream Repo

**Objective:** Prove Aether can drive a complete colony lifecycle (init, colonize, plan, build, continue, seal, entomb) in a separate downstream repo without modifying itself during the run.

## must_haves

- A Go test creates a temp downstream repo, installs Aether into it, and runs the full lifecycle
- Each step produces correct state and passes basic validation
- Aether does not write to its own source directory during the test
- The test cleans up the temp repo after completion

## tasks

### Task 1: Create downstream repo fixture

<read_first>
- cmd/e2e_v113_test.go (existing e2e patterns)
- cmd/init_cmd_test.go (init test patterns)
</read_first>

<action>

   c. Sets up a minimal Go module or empty project
   d. Returns the path

### Task 2: Implement full lifecycle test

<read_first>
- cmd/init_cmd.go (init flow)
- cmd/codex_plan.go (plan flow)
- cmd/codex_build.go (build flow)
- cmd/codex_continue.go (continue flow)
- cmd/seal_final_review.go (seal flow)
- cmd/entomb_cmd.go (entomb flow)
</read_first>

<action>
1. Write `TestFullLifecycleInDownstreamRepo`:
   a. Create downstream repo
   b. Run `aether init "Build a test feature"` — verify COLONY_STATE.json created with goal
   c. Run `aether colonize` — verify survey artifacts created
   d. Run `aether plan` — verify phases generated in COLONY_STATE.json
   e. Run `aether build 1` — verify build manifest and claims created
   f. Run `aether continue` — verify phase advances, learnings captured
   g. Run `aether seal` — verify colony sealed
   h. Run `aether entomb` — verify archive created
2. After each step, assert expected files exist and state is correct
3. Ensure AETHER_ROOT env var points to downstream repo, not Aether source
</action>

<acceptance_criteria>
- `go test ./cmd/... -run TestFullLifecycleInDownstreamRepo -count=1 -v` passes
- Test completes all 7 lifecycle steps without error
- No files are modified in the Aether source directory during test execution
</acceptance_criteria>
