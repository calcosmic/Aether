# Plan 151-03: Public Utility Commands Test Coverage

**Objective:** All 9 remaining public utility commands (preferences, pause-colony, resume-colony, data-clean, insert-phase, quick, verify-castes, bump-version, maturity) have test files with executable evidence.

- Each of the 9 commands has at least one test that executes it

### Task 2: Add tests for commands without coverage

<read_first>
- cmd/testing_main_test.go (test helpers: saveGlobals, resetRootCmd, forceJSONOutputModeForTest)

<action>
1. For each command WITHOUT a test, create a minimal test:
   a. `TestPreferences` — runs `aether preferences "test preference"` and verifies output
   b. `TestPauseColony` — runs `aether pause-colony` and verifies state file created
   c. `TestResumeColony` — runs `aether resume-colony` and verifies state restored
   d. `TestDataClean` — runs `aether data-clean` and verifies artifacts removed
   e. `TestInsertPhase` — runs `aether insert-phase` and verifies phase inserted
   f. `TestQuick` — runs `aether quick "test question"` and verifies output (mock invoker)
   g. `TestVerifyCastes` — runs `aether verify-castes` and verifies output structure
   h. `TestBumpVersion` — runs `aether bump-version --dry-run 1.0.0` and verifies output
   i. `TestMaturity` — runs `aether maturity` and verifies output structure
2. Each test:
   - Calls saveGlobals(t), resetRootCmd(t)
   - Sets up temp dir with .aether/data/
   - Sets AETHER_ROOT to temp dir
   - Executes the command via rootCmd.Execute()
   - Asserts expected output or state change
   - Cleans up via t.Cleanup
</action>
