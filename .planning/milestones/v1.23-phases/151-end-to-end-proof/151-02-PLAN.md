# Plan 151-02: End-to-End Tests Through TS Host Layer

**Objective:** End-to-end tests prove that build, continue, seal, plan, and colonize work correctly through the TypeScript host dispatch path — not just the Go CLI path.

## must_haves

- E2E tests for 5 lifecycle commands through the TS host layer
- Tests verify host produces valid dispatch manifests
- Tests verify Go runtime processes host manifests correctly
- Tests run without requiring real AI provider credentials
