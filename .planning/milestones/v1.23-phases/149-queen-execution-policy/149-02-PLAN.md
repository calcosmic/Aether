# Plan 149-02: Fix Continue Wrapper / Runtime Contradiction on Watcher Spawning

**Objective:** Resolve the contradiction where the continue wrapper passes `--skip-watchers` for standard depth, but the Go runtime's `isAlwaysRequired()` says watcher is ALWAYS required for continue.

## must_haves

- The continue wrapper and Go runtime agree on whether watcher spawns at standard depth
- The fix is documented and tested
- Both `--skip-watchers` and `--classic-ceremony` paths behave consistently

### Task 2: Decide and implement the fix

<read_first>
- cmd/codex_continue.go (full continue command)
- cmd/codex_continue_plan.go (continue plan / manifest generation)
</read_first>

<action>
**Decision needed:** Two options:

**Option A (Recommended):** Remove `--skip-watchers` from the continue wrapper's standard path. The wrapper should let the Go runtime decide what to spawn based on depth. The runtime already has correct logic (watcher is always required for continue). This is the safer fix because it trusts the runtime.

**Option B:** Change Go runtime's `isAlwaysRequired()` to NOT require watcher for standard continue. This would make the runtime match the wrapper. But this is risky because watcher provides verification that continue needs.

**Implement Option A:**
1. In `.claude/commands/ant/continue.md`, change the normal path from:
   ```
   aether continue --skip-watchers --verification-depth standard $ARGUMENTS
   ```
   to:
   ```
   aether continue --verification-depth standard $ARGUMENTS
   ```
2. In `.aether/commands/continue.yaml`, update the equivalent path
3. Update the wrapper's explanation text to match
4. Document that `--skip-watchers` is only for the light path, not standard
</action>

<acceptance_criteria>
- The continue wrapper no longer passes `--skip-watchers` for standard depth
- The light path still passes `--skip-watchers` (or equivalent light behavior)
- The wrapper text explains that standard depth may spawn watcher+probe
</acceptance_criteria>
