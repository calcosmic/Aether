<objective>
The Queen file (`QUEEN.md`) is where a lesson graduates from "something one worker noticed" to "something every future worker is told". The promotion machinery already runs at the end of every check — but the gate it enforces is "this instinct has been used at least three times", and nothing in the runtime has ever recorded a single use. So nothing was ever promoted. This plan records real uses: when an instinct's text genuinely appeared inside a worker's brief on a phase that then passed, that counts once.

Purpose: close FEED-03 — the last starved link between an observation and the Queen file.
Output: `cmd/instinct_application.go`, plus a reported `QueenPromoted` list on the phase-end summary.
</objective>
