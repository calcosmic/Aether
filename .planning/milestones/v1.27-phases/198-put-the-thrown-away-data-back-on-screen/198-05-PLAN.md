<objective>
Show how long each helper took and how many tool calls it made — on the live finishing line
and in the closing summary, from one measured source.

Purpose: the runtime already measures both. The duration is on the live line but not in the
summary; the tool-call count exists on the worker result and is read nowhere at all, and the
continue result struct has no field to carry it, so it cannot even reach the chat path. This
is the largest single "carried but thrown away" item in SHOW-02.

Output: a serialized `ToolCount` on the continue worker-flow step, one shared figure formatter
used by both the live line and the summary, and tests proving an unmeasured figure is shown as
not reported rather than as zero.
</objective>
