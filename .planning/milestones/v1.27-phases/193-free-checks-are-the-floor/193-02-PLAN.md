<objective>
Plain English first: a single piece of work is currently checked twice — once by a reviewer sent at the end of the build, and again by a reviewer sent when you run the "check and move on" command. That is most of why a one-task bug fix costs eight helpers today. This plan makes the build side run the free automatic checks only, and leaves all reviewing to the later step, so nothing is reviewed twice unless you deliberately ask for it.

Technically: implements D-08 / FLOOR-04. The build-side "verification" stage stops dispatching a watcher off the implicit required-caste floor and dispatches one only when the Queen's proposal explicitly named it. Build finalize records the deterministic check results as a report on the attempt journal, never as an advancement gate. `TestPhaseVerifiedOnce` asserts the no-double-dispatch invariant over a real manifest plus continue plan pair.

Purpose: remove the duplicate verification dispatch this milestone's measured baseline is built on.
Output: a build plan that reviews nothing implicitly, a recorded free-check report, and the invariant test that keeps it that way.
</objective>
