<objective>
Plain English first: this makes sure that nothing you can type, and no setting the system chooses for itself, can turn off the program's own automatic checks. You can choose to send fewer AI reviewers — that is the point of the speed settings — but the build, type, lint and test checks, the "do the files really exist" check, and the "is there evidence for each requirement" check always run. The one flag whose help text implied otherwise is corrected.

Technically: delivers FLOOR-01. Adds `TestDeterministicChecksCannotBeSkipped`, which walks all seven reviewer-skip paths that exist today and fails if any of them leaves a deterministic check unrun, plus a proportion assertion that the executed-check set is invariant across depth, review policy and caste proposal. Corrects the `--skip-watchers` help text and adds a guard so no continue flag's documented text can claim to skip a check.

Purpose: make the floor's unskippability a runnable command, not a claim.
Output: the FLOOR-01 test and corrected owner-facing flag text.
</objective>

    - `TestDeterministicChecksCannotBeSkipped`: a table with one row per skip path — the skip-watchers flag; light depth; heavy depth; an explicit verification depth of light, standard and heavy; a caste proposal naming no reviewer; an unavailable worker provider; the host-boundary skip; and the consecutive-failure auto-skip at or above the threshold.
