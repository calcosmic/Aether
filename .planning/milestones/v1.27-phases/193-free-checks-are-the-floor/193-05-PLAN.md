<objective>
Plain English first: two changes. First, the automatic checks now run only over the part of the project the work actually touched, and run over everything at the end and when the system cannot tell what was touched — so ordinary work is quicker without losing the final full sweep. Second, when a check fails and no AI reviewer was sent, the system sends exactly one helper to fix it and then stops; if the check still fails after that, it stops and tells you the one command to run yourself. It never sends a reviewer to diagnose first, and it never tries twice on its own.

Technically: implements D-07 (targeted per phase, full at the end; a timed-out check is a failed check), D-01's card data field, and D-02/D-03 (one bounded builder fix attempt, recorded append-only in the attempt journal with its own reason and counted separately, fed by a compact failure index rather than the whole log).

Purpose: make the floor affordable to run every time, and give a failing floor one honest bounded recovery.
Output: a scoping function with a full-run fallback, the report's card data fields, and the single-fix-attempt path.
</objective>
