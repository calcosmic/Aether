<objective>
Plain English first: today, when Aether finishes a piece of work, it can hand the final "is this actually done?" judgement to an AI reviewer — and if nothing mechanical could be run, it hands the whole judgement to that reviewer. This plan makes the program's own automatic checks the thing that decides. A job with no reviewer still gets checked, moves forward when the checks pass, and is stopped when they fail.

Technically: this is the phase's tracer — one thin, production-quality vertical slice through every layer the phase touches (criterion evidence evaluator -> continue verification pipeline -> gates -> advancement), proven end to end by running the real compiled `aether` binary against a fixture colony with zero reviewer workers, in both directions. It then extracts that proven slice into a single shared function both continue lanes call, so lane parity is a structural fact rather than a reminder.

Purpose: prove the deterministic-floor architecture end to end before any horizontal expansion. Everything else in Phase 193 builds out from this slice.
Output: `runDeterministicFloor` (the single floor body), reviewer-free criterion evaluation, and the FLOOR-02 both-directions black-box proof.
</objective>

- **Noun that is now primary:** the *deterministic verification result* (build/types/lint/tests + claimed-files-exist + criterion evidence), not the reviewer worker's verdict.
- **Decision:** `promote`. The deterministic floor is promoted to the primary verification anchor; the reviewer verdict is demoted to one optional additional evidence source that can only ever *add* a block, never supply the pass by itself. This is the promote-not-add-alongside move: the old specific anchor (an executed Watcher review) becomes a detail of one variant rather than a second still-required anchor.
- **Rationale:** adding the free checks alongside a still-required reviewer is exactly the condition ruling D11 was written to end — it is what makes a one-task bug fix cost eight workers.
- **Companion invariant test (adopted, not merely suggested):** `TestDeterministicFloorIsTheOnlySourceOfAPass` in `cmd/deterministic_floor_test.go` — a reviewer verdict alone can never flip `ChecksPassed` from false to true.
