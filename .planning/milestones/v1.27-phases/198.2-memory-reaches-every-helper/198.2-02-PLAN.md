<objective>
Make a finished deep-research run reach the next helper by itself.

Today `finalizeOracleLoop` already calls `saveOracleResearchDocument` when a run completes (cmd/oracle_loop.go:1356-1366) — but it stops there. The saved path is never recorded in the colony's `research_docs` list, which is the only thing `loadColonyResearchDocs` reads, so the build brief (`codex_build.go:3349`), the planning brief (`codex_plan.go:2177`) and the research-scout brief (`phase_research.go:136`) all see nothing. The owner has to type `aether oracle save` and then `--research <path>` by hand. A run the owner stops (`cmd/oracle_loop.go:570-606`) files nothing at all, so everything it paid for is thrown away.

Purpose: research the owner paid for should reach the next helper without a second and third hand-typed command.
Output: automatic filing, automatic registration, a partial label on interrupted runs, and automatic promotion of strong findings into labelled learned habits.
</objective>
