<objective>
Give the planner, the builder and the research helper the codebase map's actual content.

Today the map reaches a brief as a list of filenames plus an age notice (`resolveSurveySection`, cmd/helpers.go:200-243). Seven survey reports — about 123 KB in this repository, dated 2026-05-19 — are never read into any prompt.

Purpose: a helper handed a filename has to go and read it, or guess. A helper handed the content does not.
Output: one deterministic map digest with its own budget and an age line, wired into all three briefs from one call site each.
</objective>

## Scope note: why this is two plans, not one

This plan originally carried WIRE-02 (showing the research helper the shared cross-project lessons) as a third task, projecting about 110K tokens against a 100K working budget with thirteen new tests in one sitting. WIRE-02 now lives in plan 08.

The split is by file, not by convenience: plan 08 touches `cmd/phase_research.go` and `cmd/codex_plan.go`, both of which this plan also edits, so plan 08 runs in wave 3 behind this one rather than beside it. That ordering is required anyway — plan 08 edits the same `renderPhaseResearchBrief` function this plan's Task 2 injects the digest into, and two helpers editing one function in the same wave is exactly the collision the wave rules exist to prevent. Plan 08 is disjoint from plan 07, the other wave-3 plan.
