# Phase 198.2 Plan 08: Shared Cross-Project Lessons Reach the Research Helper Summary

**The research Scout's brief now carries the same top-5 shared cross-project lessons (hive wisdom) every other helper is shown, from the one existing selection function; the instruction that used to ask it to write a summary of nothing, and the hardcoded "No relevant hive wisdom found" fallback line, are both gone.**

## Accomplishments

- `resolveResearchSharedLessonsSection()` (`cmd/phase_research.go`) reads the colony's domain tags from the hub registry and calls the exact same `readHiveWisdomEntriesForDomains(hubDir, 5, domains, &fallbacks)` + `buildHiveWisdomLines` the memory pack (`cmd/colony_prime_context.go`) already uses -- same function, same literal limit, same domain source, no second selection rule. Wired into `renderPhaseResearchBrief` as a new "## Shared Lessons (Cross-Colony Patterns)" section, omitted entirely when there is nothing to show (empty store, unmatched domain, or `AETHER_HIVE_POLICY=off`).
- The output-template instruction that told the Scout to fill a "## Hive Wisdom (Pre-existing Knowledge)" section from nothing -- with a hardcoded `"No relevant hive wisdom found"` fallback for when it had nothing to say -- is removed from `renderPhaseResearchBrief`'s six-section template, which is now a five-section template. The Scout now summarises content it was actually shown, instead of being asked to invent or fake a summary.
- The matching hardcoded stand-in in the fallback RESEARCH.md template (`writePhaseResearchArtifacts`, `cmd/codex_plan.go`, written when no research worker ran for a phase) is also removed, along with the empty heading it sat under; the rest of that template (Key Patterns, External Context, Gotchas, Recommended Approach, Files to Study) is unchanged.
- 5 new tests in `cmd/scout_hive_198_2_test.go`: a shared-lesson reaches the brief; an equality assertion proves the brief's selection is byte-identical to the memory pack's own selection (not a research-specific limit or domain source); the cross-project switch is honoured; an empty store omits the section entirely with no stand-in; the fallback template invents nothing.
- Two pre-existing tests that asserted the now-removed heading (`TestPlanResearchDispatchCarriesSixSectionMission`, `TestPhaseResearchTemplateCarriesSixSections`) were updated and renamed to `...FiveSectionMission` / `...FiveSections` -- required by the plan's own `go test ./cmd/ -run 'TestPhaseResearch|TestPlanResearch'` verification command, since they are outside this plan's declared file scope but directly test the behaviour WIRE-02 removes.
