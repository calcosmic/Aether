<objective>
Make the greeting the program prints on a new, resumed or cleared chat carry what the colony actually remembers, instead of only pending questions and flags.

`hook-session-start` (cmd/hook_cmds.go:334) renders `renderNextActionCard` (cmd/next_action_card.go:39), which today shows where things stand, what changed, what is waiting on the owner, the recommended command, and whether it is safe to close the chat. It says nothing about the owner's own preferences, nothing about what the colony has learned, and nothing about what the last helper left behind.

Purpose: the first thing the owner sees each session should prove the system remembers them.
Output: three new content lines on the session greeting only, each omitted when its source is empty, sharing one instinct-ranking rule with the project dashboard.
</objective>
