# Phase 198.2 Plan 03: Memory Reaches the Session Greeting Summary

**The session-start greeting now names the owner's own preferences, the three strongest habits the colony has learned, and what the last helper left behind -- sharing one confidence-ranked "strongest" rule with the status dashboard, and touching nothing else.**

## Performance

- **Completed:** 2026-08-30T14:37Z
- **Tasks:** 3 completed

## Accomplishments
- Settled the discrepancy CONTEXT.md flagged: `loadRecentRuntimeInstincts` never existed; `cmd/status.go` already called the correctly-named `loadStrongestRuntimeInstincts`. Deleted a dead, never-called, recency-ordered second selector (`recentInstinctEntries`) that had the exact shape of a landmine second ranking rule, and locked the single-rule invariant with an AST scan that fails by name if a second one ever calls `memory.InstinctUsefulnessScore`.
- Added `nextActionMemory` (preferences summary, up to 3 habit sentences, one relay-note sentence) to the shared `nextAction`/`nextActionInput` types, populated ONLY by the new `loadNextActionInputForGreeting()` -- the one and only caller is `hookSessionStartCmd`, so every other closing card this program prints stays byte-clear of the new content.
- `renderNextActionMemory` renders the block after "Your standing instructions" and before the Next Up funnel, omitting each of the three parts individually when its source is empty -- no "nothing learned yet" filler, no empty heading.
- Proved, by temporarily breaking each guarantee and watching the named test fail (then restoring): removing the render call breaks `TestGreetingCarriesPreferencesHabitsAndTheLastNote`; planting a write inside `loadNextActionInputForGreeting` breaks `TestGreetingWithMemoryStillDoesNotMutate`; planting a synthetic second ranking function is caught by `scanInstinctRankingSource`.
- Updated CLAUDE.md's "Session Recovery" section to name what the card now carries and every test that makes each claim true, without reintroducing the delegated-to-the-assistant instruction shape `TestSessionGreetingIsNotDelegatedToTheAssistant` guards against.
