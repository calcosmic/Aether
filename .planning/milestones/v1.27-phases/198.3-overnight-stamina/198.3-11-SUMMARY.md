## Decisions Made

- Capability material is excluded from stable checkpoint identity; type, phase, normalized subject, session, and goal remain the sole identity inputs.
- Rotating an unresolved checkpoint appends a hash instead of invalidating earlier displayed commands, matching the forced-reviewer precedent.
- Resolved checkpoint questions stay reserved for the protected public route so replay cannot append a shadow clarification.
- The generated checkpoint flag normalizes to the existing transient owner-capability slot. The checkpoint and reviewer resolvers still validate against separate hash fields, while generic command discovery remains unchanged.
