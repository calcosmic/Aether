## Decisions Made

- Kept lifecycle data independent of CLI surface. Deleting dead Cobra adapters does not delete state that the supported `run` and `status` commands still own.
- Used AST identifiers for the production-source ratchet so an explanatory comment cannot look like a live scanner declaration or call.
- Preserved exact current-path orphan metadata before consulting frozen pre-migration metadata; later reviewed dispositions therefore cannot be erased by regeneration.
- Required runtime resolution only for the live allowlist. Both baseline files remain immutable historical evidence and are still required to use full `aether ...` path syntax.
- Kept the new focused assertions as subtests of already-inventoried wiring guards so the dedicated CI wiring step continues to execute them without widening shared filter ownership.

- **Fix:** Surviving exact paths now keep current reviewed metadata, frozen metadata is fallback-only, live entries remain runtime-resolvable, and historical baseline entries retain full-path syntax without current-resolution coupling.
