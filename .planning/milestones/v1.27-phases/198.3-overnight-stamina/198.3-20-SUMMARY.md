## Decisions Made

- Current phase statuses are compared by stable phase ID with the active revision's immutable phase snapshot. Phases already complete at acceptance do not count toward the new cadence.
- Every same-revision replan row, including owner-resolved rows, represents a handled boundary. Rows from other revisions cannot advance the active cadence.
- Headless persistence and interactive pause both use the projection's exact checkpoint phase rather than whichever phase happens to be current in the invocation.
- Legacy plans with no usable revision snapshot count all currently completed phases from the beginning of that stable plan definition.
