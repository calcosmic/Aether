Output: versioned persisted report, shared run/status rendering, and bounded internal recovery advice. Plan 08 performs the behavior-neutral public command cleanup afterward.
</objective>

## Trust Boundaries

| Boundary | Risk | Mitigation |
|---|---|---|
| clocks/ledgers -> report | Recomputed or estimated values could mislead owner | Persist timestamps and measured rows at finalization; status reuses record; no estimate path |
| run stop -> recovery log | Queueable/normal events could pollute failure history | Typed disposition/class allowlist; table tests; idempotent current-phase write |
| recovery state -> Medic advice | Stale/budget-exhausted record could recommend unnecessary work | Reuse existing eligibility/budget helper; advice only; no dispatch |
| report persistence failure | Owner could receive success text without durable handoff | Finalizer surfaces persistence failure and retains primary outcome in returned result; tests inject failure |
</threat_model>
