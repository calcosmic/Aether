## Shared Patterns

### Two-group deletion strategy (from RESEARCH.md Pitfall 1)

**Source:** RESEARCH.md, Runtime State Inventory table and Pitfall 1 section
**Apply to:** All 296 tracked artifacts

The 296 files split into two groups with different `git rm` semantics:

**Group 1: Full delete** (local + git index). These are stale artifacts with no local value.
```bash
# Stale agent mirror (26 files, duplicates of agents-claude/)
git rm -r .aether/agents/

# Chamber archives (241 files, stale colony data from Feb-Apr 2026)
git rm -r .aether/chambers/

# Runtime state files from self-hosting colony (2 files)
git rm .aether/CONTEXT.md .aether/CROWNED-ANTHILL.md

# Orphaned worktree files (7 files, Phase 44 artifacts with canonical copies)
git ls-files .claude/worktrees/ | xargs git rm
```

**Group 2: Untrack only** (`--cached`, preserve local copies). These are active runtime files that the developer still needs locally.
```bash
# Active colony state
git rm --cached .aether/data/COLONY_STATE.json

# Dream journals (11 files including .gitkeep)
git ls-files .aether/dreams/ | xargs git rm --cached

# Midden failure logs (3 files)
git ls-files .aether/midden/ | xargs git rm --cached

# Settings and rules (generated by aether install)
git rm --cached .aether/settings/claude/settings.json
git rm --cached .aether/rules/aether-colony.md

# Registry, version, QUEEN.md (runtime files)
git rm --cached .aether/registry.json .aether/version.json .aether/QUEEN.md
```

**Critical:** Forgetting `--cached` on Group 2 will delete active local state (COLONY_STATE.json, dream journals). This is the single highest-risk pitfall.

### Gitignored-but-tracked file removal (from RESEARCH.md Pitfall 4)

**Source:** RESEARCH.md, Pitfall 4 section
**Apply to:** `.claude/worktrees/` (7 files) and `.aether/data/`, `.aether/dreams/`, `.aether/midden/` (already gitignored but still tracked)

Files committed before a `.gitignore` rule remain tracked even after the rule exists. The removal pattern is:
```bash
# For directories that are already gitignored but have tracked files:
git ls-files <path> | xargs git rm --cached   # untrack without deleting local
# OR
git ls-files <path> | xargs git rm             # untrack AND delete local
```

Do NOT use `git rm -r <path>` directly on gitignored directories -- it may fail with "did not match any files" because glob expansion skips gitignored paths.
