## Key Decisions

1. **Wrappers are host-assisted orchestrators** — call `aether host` for manifests, handle colony ceremony, but do not mutate state or duplicate verification
2. **Lifecycle simulation is opt-in only** — `--simulate` flag required; missing platforms without it produces an error
3. **Doc-CLI alignment blocks releases** — host-critical flag mismatches fail the smoke test and block the release gate
4. **Oracle state uses atomic storage** — same pattern as colony state, with interrupt recovery
