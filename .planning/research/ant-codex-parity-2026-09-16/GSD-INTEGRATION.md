- The owner has moved Codex lifecycle-skill work into the current milestone. This explicitly supersedes the earlier “later milestone” deferral in the active roadmap, requirements, project description, and Phase 205 context.
- The existing 65 requirements and 72 Classic capability rows retain their primary ownership and evidence history. Sixteen new `ANT-*` requirements bring the active requirement total to 81; they do not manufacture new Classic capability rows or re-sign old proof.
- Reuse the completed Classic mechanism studies and the three research reports. Revalidate the relevant current entrypoints when writing each plan; do not repeat the broad owner interview or infer implementation details from feature names.
- Keep ordinary team selection proportionate. A live proof can explicitly request an independent Watcher, but must also prove the default small-job path remains one Builder plus the runtime's required checks.
- Native helpers need real runtime assignment/result binding. Current native delegation exists; every required nesting, permission, cancellation, and workspace behavior still needs evidence on the supported host. Old categorical claims that Codex cannot delegate are not current acceptance evidence.
- Shared recruitment/workspace/Swarm defects are owned by Phase 204.4, with Claude/OpenCode regression checks. Codex-specific repairs must not create another state or authorization authority.
- Missing provider usage stays unavailable. Count checks, real outcomes, and evidence; do not turn missing costs, model answers, or unsupported host abilities into invented success.
