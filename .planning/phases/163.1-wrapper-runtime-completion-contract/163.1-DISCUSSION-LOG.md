## Reconcile escape hatch

| Option | Description | Selected |
|--------|-------------|----------|
| Read-only artifact evidence | Hash-verified criterion satisfaction without a modification claim | ✓ (Claude) |
| Cross-task claim satisfaction | Any task's claims in the same build satisfy a bound artifact | |
| Criterion rebind | Edit the criterion post-build without full redispatch | |

**Rationale:** covers the observed M4L failure (test-only task, criterion
bound to an untouched file) without ever legitimizing a false claim;
`ArtifactEvidence` field already exists to build on.

## Contract source of truth

| Option | Description | Selected |
|--------|-------------|----------|
| Go structs canonical, schema generated | Generator emits JSON Schema from runtime types; drift fails tests | ✓ (Claude) |
| Schema file canonical | Go validates against shipped schema at runtime | |
| Independent artifacts + drift tests only | No generation; tests assert agreement | |

**Rationale:** matches "runtime owns truth"; generation kills the
freshness-class drift bug at the root; docs pinned by invariant tests.

## Failure report shape

| Option | Description | Selected |
|--------|-------------|----------|
| Atomic packet, all violations reported at once | Structured details list + human summary; retry is cheap | ✓ (Claude) |
| Per-worker quarantine | Accept valid workers, drop invalid ones | |

**Rationale:** partial acceptance creates split-brain staging state; with
attempt rebinding (D-08) atomic retry is cheap and simpler.

## Attempt recovery model

| Option | Description | Selected |
|--------|-------------|----------|
| Validate-at-stage + rebind-while-nonterminal + stable worker names | All three together | ✓ (Claude) |
| Validate-at-stage only | Prevents poisoning but rejected packets still force new attempts | |
| Rebind only | Recovers but stale packets can still bind | |

**Rationale:** the two mechanisms close different halves of the observed
lockout; stable names (D-09) remove the manual result-remapping that nearly
lost ten workers' results in the M4L session.
