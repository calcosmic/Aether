## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| wrapper-spawned worker → runtime | Untrusted (possibly LLM-authored) JSON completion packet crosses into `cmd/` | completion packets, claims, file paths |
| completion packet → colony state | Accepting a packet mutates `COLONY_STATE.json`, claims, attempt journal | colony state |
| wrapper → attempt journal | Staging writes durable state on behalf of untrusted worker output | packet digest, durable packet file |
| runtime → wrapper (brief file) | Runtime writes a brief file; wrapper injects contents into a worker prompt verbatim | worker instructions |
| repository documentation → shell execution | `extractVerificationCommands` output is executed as a shell command | shell commands |
| operator CLI → criterion gate | `--read-only-artifact` relaxes a phase-advancement gate | evidence records |
| plan manifest → continue-finalize | Wrapper-held, externally round-tripped document carries a gate-relaxation request | manifest fields |
| source checkout → hub (`~/.aether/`) | Publish writes files every colony on this machine trusts; schema is published | schema, version metadata |
| third-party Go module → build | Two new validation dependencies in the supply chain | JSON schema validation |
