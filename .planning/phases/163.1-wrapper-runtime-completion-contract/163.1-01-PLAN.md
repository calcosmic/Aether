## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| wrapper-spawned worker → runtime | Untrusted JSON completion packet crosses into `cmd/`; this plan defines the shape it is checked against |
| third-party Go module → build | Two new dependencies enter the supply chain and run at packet-validation time |
| source checkout → hub (`~/.aether/`) | The generated schema file is published to every colony via `aether publish` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-163.1-01 | Tampering | `.aether/schemas/completion-packet.schema.json` hand-edited to loosen validation | mitigate | `contract-schema --check` regenerates from Go structs and byte-compares; `compiledCompletionPacketSchema()` compiles from generated bytes, never from the on-disk file, so an edited file cannot weaken runtime validation |
| T-163.1-02 | Tampering / Elevation | New third-party modules `invopop/jsonschema`, `santhosh-tekuri/jsonschema/v6` | mitigate | Pin explicit versions in go.mod (no floating `latest`); `go mod verify` in acceptance criteria; both are validation-only libraries with no filesystem or network access at call sites |
| T-163.1-03 | Denial of Service | Deeply nested or huge submitted packet driving pathological schema validation | accept | Packets are local files produced by a wrapper on the user's own machine, not remote input; the existing finalize path already reads the whole packet into memory before this stage |
| T-163.1-04 | Information Disclosure | Generated schema published to `~/.aether/` hub | accept | Schema contains only field names and types already documented publicly in `build.md` and the handoff contract; no secrets, paths, or user data |
| T-163.1-05 | Spoofing | `contract-schema --check` mutating state under the guise of inspection | mitigate | `--check` is read-only by construction; acceptance criteria assert `git status --porcelain .aether/schemas/` stays empty after a check run (guards the `consolidation-phase-end --dry-run` bug class) |
</threat_model>
