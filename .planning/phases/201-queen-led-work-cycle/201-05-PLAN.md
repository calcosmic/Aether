<objective>
Delete one of the two review passes by making both of them read the same recorded boundary, and tell the owner the honest truth when a build finishes before verification has run.

Purpose: `.planning/codebase/CONCERNS.md` names the same phase being verified twice — a build-side Watcher and a check-side Probe or Auditor — because build and check independently derive the same required caste from the same phase content. That is duplicated work the owner pays for in wall-clock time twice per phase. Plan 201-03 made the boundary one recorded fact; this plan makes both dispatchers obey it.
Output: Boundary-gated reviewer dispatch on both sides, a non-regression proof for the one-worker ordinary case, and an honest unverified build card.
</objective>
