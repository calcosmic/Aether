<objective>
Give the work cycle a complete outcome vocabulary and make every outcome earn the same full closeout ceremony.

Purpose: The owner's complaint is not that work fails — it is that a failure looks like a shrug while a success looks considered. D-05 says a partial result must look as considered as a success, with only the verdict differing. That is an invariant a test can hold, and holding it structurally is what stops a future non-success path quietly shipping a two-line card.
Output: A closed six-verdict vocabulary, a total mapping onto the existing lifecycle outcome kinds, and an equal-ceremony invariant test.
</objective>

  <action>Create `pkg/colony/work_outcome.go`. Give it `Valid()`, `MarshalJSON` and `UnmarshalJSON` methods following the exact discipline `OutcomeKind` already uses in `pkg/colony/lifecycle.go`: an unknown value fails to decode rather than being coerced.
