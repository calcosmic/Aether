<objective>
Make the Queen's build-end-versus-check-step choice a real, recorded fact on every build attempt.

Purpose: the reconciliation function and the read path both exist and pass their own tests, but nothing in production has ever proposed or persisted a boundary. The check step therefore always reviews, on every phase, with no exception and no way for the coordinator to say otherwise. This plan gives the choice an input channel, reconciles it exactly once, applies it to the same build's own dispatch list, and writes it onto that build's attempt.
Output: a boundary proposal channel on `aether build`, one reconciliation per build, a persisted decision on both build lanes, and a wiring test that fails if either half is removed.
</objective>
