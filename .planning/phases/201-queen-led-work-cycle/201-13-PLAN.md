<objective>
Measure a real one-plan job, then set the turnaround target from that measurement — with the owner confirming the job was representative before the number is ratified.

Purpose: The owner named this the reason he stopped using the tool: a one-plan job costs about thirty minutes, with the test suite the largest term. D-13 refuses to let this phase pick a target out of the air. Plan 201-12 built the instrument; this plan takes the reading and writes down what "fast enough" means, so the levers in the next plan have a number to move and a later regression is detectable rather than arguable.
Output: A baseline document with the eight measured segments, an owner-confirmed representative job, and a stored ratified target.
</objective>
