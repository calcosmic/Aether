<objective>
Make one accepted goal enough: the controller picks the next transition itself, reports it through the same result model everything else uses, and stops only where a person is genuinely required.

Purpose: The phase's fifth success criterion asks for one accepted goal to move through survey, planning, work, verification, bounded repair, replan, rollback, resume and ready-to-seal without phase-number choreography. Autopilot already has the policy machinery; what it lacks is consuming the same accepted result the other two lanes now consume.
Output: Goal-level transition selection, four declared stop boundaries, and a proportionate quick fast path on the same evidence model.
</objective>
