<objective>
Make a result card tell the exact truth about files and hand the owner exactly one thing to do next.

Purpose: A partially finished job that reports the project as built is the failure mode this repository has shipped before. The two-stage receipt boundary already decides what is genuinely credited; what is missing is saying out loud which edits are credited, which are not, and where the uncredited ones are — and then, after a non-success, naming one next action instead of a menu.
Output: Credited and orphaned file precision on every card, one derived next action with its reason and alternatives, and attempt-bound plan-versus-reality evidence.
</objective>
