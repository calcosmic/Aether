<objective>
Give failure one bounded, announced, reversible repair round — and stop there.

Purpose: A repair loop that keeps trying is how a bad change gets buried under three more. D-09 fixes the shape: save a checkpoint, try once, verify once, and if it still fails put the project back exactly where it was and hand the owner the evidence. D-10 makes both moves visible so the owner is never guessing what state his project is in.
Output: One repair round reusing the existing budgeted receipt ledger, announced save and restore, and a handback that answers the owner's four questions.
</objective>
