<objective>
Measure where the thirty minutes actually go, one job at a time, without inventing a single number.

Purpose: The owner stopped using this tool because a one-plan job takes about half an hour. D-13 refuses to set a target from aspiration: this plan builds the measurement first. The single most likely way to get this wrong is to fill a segment nobody instrumented by subtracting the others, which produces a plausible number for something that was never measured — the same failure that once shipped a token undercount behind a green test.
Output: An eight-segment attempt-bound timing record, real instrumentation points, a one-line closeout summary, and a guard that keeps it report-only.
</objective>
