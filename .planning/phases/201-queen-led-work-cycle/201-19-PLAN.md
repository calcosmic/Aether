<objective>
Make a finished build actually tell the owner what happened: the verdict, the honest state of verification, what files were credited and what was left orphaned, and the one thing to do next.

Purpose: the closeout rendering layer for all of this is built, unit-tested, and connected to nothing. No production call site anywhere sets a work verdict, so a person running a build today sees exactly the screen they saw before this phase — no verdict, no recommendation, no file card, no honest "not verified yet". This plan supplies the verdict from the attempt the build actually sealed, on both build lanes.
Output: one resolver from sealed attempt to verdict-carrying closeout, wired into the direct build lane and the wrapper build closeout, with the file-precision card rendered where the data exists.
</objective>
