## Decisions Made

- Kept the persisted report as the historical authority. Live status may show separate current information, but it cannot mutate or recalculate the last invocation's story.
- Reused the Phase 196 ledger and Phase 197 next-action authorities directly so the report introduces neither inferred cost nor a competing command-decision table.
- Reused internal recovery helpers rather than invoking public Cobra adapters, leaving plan 08 free to remove those adapters without changing supported run behavior.
- Preserved the existing `autopilot/state.json` status value for genuine stops (`paused`) because consumers already depend on it; the new report supplies the more precise `genuine_stop` outcome.
