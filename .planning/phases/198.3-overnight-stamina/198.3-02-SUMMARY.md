## Decisions Made

- Kept compatibility for legacy top-level findings only when `artifacts.review` is absent; an explicit artifact always wins.
- Treated invalid artifacts as reportable evidence errors rather than silently manufacturing a failing score.
- Stored checkpoint records with their own queueable types instead of persisting them as blocker flags; blocker shape is synthesized only at seal.
- Used stable keys containing checkpoint type, phase, normalized subject, and current decision scope so retries update one record without leaking across colony sessions/goals.
- Preserved historical owner-confirmation seal behavior as a fallback, deduplicated by the exact recovery command when a durable runtime checkpoint exists.
