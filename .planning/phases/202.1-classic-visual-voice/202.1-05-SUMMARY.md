# Phase 202.1 Plan 05: Close the Lifecycle Event Identifier Leak Summary

**Fixed `pauseResumeLifecycleEvent` (the pause/resume event writer) rather than `nextActionEventSentence` (the what-next card reader): a new `lifecycleEventSentence` type, produced only by two sentence constructors covering all seven pause boundaries and all four recovery-provenance values, and an AST guard that refuses any future bypass of that type anywhere in the `cmd` package.**

## Performance

- **Duration:** ~45 min
- **Completed:** 2026-09-12
- **Tasks:** 2
- **Files modified:** 2 (1 created, 1 modified)

## Accomplishments

- **Task 1 (TDD):** Added `lifecycleEventSentence`, a named string type, to `cmd/session_flow_cmds.go`. Added `pauseBoundarySentence(boundary string)`, switching over `pauseSafeBoundary`'s exact seven return values (`worker_completion_boundary`, `interrupted_attempt_boundary`, `interrupted_execution_boundary`, `post_build_verification_boundary`, `completed_episode_boundary`, `idle_command_boundary`, `between_commands_boundary`) plus an unrecognised-value default, each producing a distinct plain-English sentence rather than echoing the raw value. Added `resumeProvenanceSentence(provenance colony.RecoveryProvenance)`, doing the same for the four declared provenance values (`confirmed`, `reconstructed`, `conflicting`, `unknown`). Changed `pauseResumeLifecycleEvent`'s signature to `(now time.Time, command string, sentence lifecycleEventSentence)`, dropping the handoff identifier from the stored record entirely (it remains durable on `colony.PauseHandoffReference`, where recovery already reads it) and updated both call sites (pause at line ~379, resume at line ~636) to pass a constructor's result. `grep -c 'handoff=' cmd/session_flow_cmds.go` now returns 0. `cmd/next_action.go` (the reader) is unmodified.
- **Task 2 (TDD):** Added `TestLifecycleEventSentenceTypeCannotBeBypassed` to `cmd/classic_voice_event_test.go` — an AST walker (following `scanNextActionHardcodeSource`'s exact structural-guard discipline) that parses every non-test `.go` file in `cmd/` and collects every conversion into `lifecycleEventSentence`. Exactly the two legitimate constructors (`pauseBoundarySentence`, `resumeProvenanceSentence`) may produce one; any other site fails by file, function, and expression. The guard asserts it found conversions inside both legitimate constructors (a scanner matching nothing fails rather than silently passing). Added `TestLifecycleEventSentenceGuardCanFail`, which plants a synthetic bypass in a temp package file and asserts the scanner locates it — the same shape `TestNextActionHardcodeDetectsAPlantedViolation` already uses in this package.
