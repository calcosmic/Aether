<objective>
Bring the planning screens — the busiest set of cards in the program and the last flat ones — up to the reference voice, on both the primary path and the fallback the owner reaches after a repair.

Purpose: RESEARCH.md's audit found the plan screen splits in two. The primary path delegates to a newer, richer planning projection, and the fallback path in the shared visuals file handles repair, existing-plan and iteration branches with `Goal:` and `Plan size:` prose and no symbols at all beyond the shared banner. Both are screens an owner actually lands on, so voicing one and not the other would leave the program reading as two programs depending on which branch fired. This plan is in the third wave because it is the only remaining plan that edits the shared visuals file, which the first and second waves already own.
Output: every planning card registered in the corpus and measuring at or above the derived figure, with the planning content the earlier phases delivered untouched.
</objective>
