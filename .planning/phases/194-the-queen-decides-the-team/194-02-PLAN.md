<objective>
Move the required-caste floor. Today an ordinary build is forced to carry a
verification caste, a coverage caste, a quality caste and often a security
caste, because the floor reads inferred phase mode, a blast-radius keyword list,
and the phase's position in the plan. This plan reduces the build floor to the
caste that writes the code and reconciles every test that asserted the deleted
rules.

Ordering rationale: this plan rewrites `cmd/queen_spawn_budget.go`, which plan
194-01 also edits (its continue branch), so the two cannot share a wave. The
floor shrink and the test reconciliation are kept in ONE plan on purpose: the
deletion falsifies nine existing tests in a single move, and any split between
them would leave a plan whose verification gate runs a red suite.

Purpose: TEAM-01, and the second third of closing `.planning/WINDOWS.md` #1.
Output: a shrunken floor, and a retirement ledger entry for every test that
asserted a rule this plan deletes.
</objective>
