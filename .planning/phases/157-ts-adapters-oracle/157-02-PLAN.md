<objective>
Build the Oracle loop stub in the TypeScript control plane. The Oracle does deep research with confidence evaluation and research planning. This phase creates the type definitions, confidence evaluator, research plan builder, and iteration runner — all as stubs that simulate the Go oracle loop behavior without making real worker invocations.

Purpose: The Oracle is the research specialist of the colony. It evaluates how confident the colony should be in its findings and plans the next research steps. Clean interfaces matter more than implementation depth — the Go runtime will eventually call these through a bridge.
Output: Oracle types, confidence evaluation, research planning, iteration runner, tests, and public API exports.
</objective>

    - `runOracleIteration(query: string, iteration: number, state: OracleState, plan: OraclePlan): Promise<{ state: OracleState; plan: OraclePlan; result: OracleWorkerResponse }>` — simulates a single research pass:
      1. Select next question via selectNextQuestion
      2. Simulate a worker response with status "answered", confidence = min(targetConfidence, 50 + iteration * 5), summary = "Simulated finding for {question.text}", one finding with evidence
      3. Update state.iteration, state.overallConfidence = evaluateConfidence(plan.questions), state.lastUpdated = now
      4. Update the question's status, confidence, keyFindings, iterationsTouched
      5. Return { state, plan, result }
    - `runOracleLoop(topic: string, options?: { maxIterations?: number; targetConfidence?: number; depth?: string }): Promise<{ state: OracleState; plan: OraclePlan; iterationsRun: number; status: string }>` — runs iterations until maxIterations or targetConfidence reached:
      1. Create initial state and plan
      2. For i = 1 to maxIterations:
         - Call runOracleIteration
         - If overallConfidence >= targetConfidence, break with status "complete"
      3. Return final state, plan, iterationsRun, status
    - `createOracleState(topic: string, options?: { maxIterations?: number; targetConfidence?: number; depth?: string }): OracleState` — returns initial state with defaults (version "1.1", phase "survey", iteration 0, status "active", strategy "adaptive", empty arrays).
    - `createOraclePlan(topic: string, targetConfidence: number): OraclePlan` — returns initial plan with version "1.1", empty sources, generated questions, createdAt/lastUpdated set to now.
    - `oracleReadyForCompletion(plan: OraclePlan, state: OracleState): boolean` — returns true if overallConfidence >= targetConfidence.
    - `snapshotOracleProgress(plan: OraclePlan, state: OracleState): { answered: number; touched: number; findings: number; confidence: number }` — returns progress snapshot.
    - `oracleProgressedSince(before: snapshot, plan: OraclePlan, state: OracleState): boolean` — returns true if any metric improved.
