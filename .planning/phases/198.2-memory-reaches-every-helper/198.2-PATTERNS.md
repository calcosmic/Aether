**Source:** `cmd/colony_prime_context.go` (every `sections = append(sections, colonyPrimeSection{...})` call site, e.g. lines 603-738)
**Apply to:** any section that *does* compete for the colony-prime budget (as opposed to the two dedicated slots above) — use the same struct fields (`name, title, source, content, priority, freshnessScore, confirmationScore, relevanceScore`) so the existing ranking-under-budget logic (`:1058`) and included/trimmed ledger (`:1083-1091`) apply automatically.

### One assembler, two lanes (D-03)

### Exactly-once section rendering guard
**Source:** D-190-05-A comments at `codex_plan.go:1499` / `codex_colonize.go:719`
**Apply to:** any place a capsule-rendered section (pheromones, handoffs, and now hive/digest) might also be rendered by a caller — check for an existing comment/guard before adding a second render call.
