<objective>
Persist, once per phase, the exact closing summary the owner saw when a check finished — so the next phase's helpers can be told what actually happened.

WIRE-07 names `build/phase-N/outcome.md`. That file has never existed in any version of this program. What does exist is `build/phase-N/verification.json` and `build/phase-N/review.json`, written by both check lanes, plus `continue.json` — but `continue.json`'s `Summary` field is a one-line derived sentence, not the closing summary the owner read. Phase 198's D-12 made one renderer produce that screen on both lanes, fed by the finalizer's own result map (`closeoutDirectVisual` -> `closeoutContinueDirectVisual` -> `renderContinueVisual` / `renderContinueBlockedVisual`).

Purpose: the next phase should hear what the last one produced, in the owner's own closing words, without anything being re-derived.
Output: `build/phase-N/outcome.md`, written from that same renderer on both lanes, and a guard that no check lane can terminate without writing it.
</objective>
