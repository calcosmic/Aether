- `func resolveJobSizeRoute(facts jobSizeFacts) jobSizeDecision` — priority-ordered exactly like `resolveVerificationDepth`: (1) an accepted plan with outstanding work means the big route, naming that fact; (2) zero matched paths means the big route, saying nothing in the project matches what was named so this is new work rather than a change to something that already exists; (3) more matched paths than `smallJobFileBudget` means the big route, naming the count; (4) otherwise the small route, naming the count. Leave the `Attempt` branch to plan 02 — for now an `Attempt` value that is not nil is simply ignored by this function.

Resolve concrete referents by walking the working tree once (skipping `.git`, `node_modules`, `.aether/data`, and anything ignored) and matching a file's base name or a path segment against the whitespace/punctuation-delimited tokens of the sentence, case-insensitively, with a bounded walk.
