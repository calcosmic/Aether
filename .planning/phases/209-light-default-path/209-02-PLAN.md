<planner_assumptions>
**UED-16, second flagged assumption (the probe left this row `unclassified`):** nothing in the source artifacts settles what evidence proves a small attempt "turned out bigger". This plan **assumes** the two honest, independently measured signals are (a) the disk-measured count of files that actually changed, compared against the same `smallJobFileBudget` the first decision used, and (b) the project's own check outcome and the resulting verdict. It deliberately excludes the helper's own summary text, because this repository already holds that a helper's account of its own work is not evidence. If the owner wants a helper's self-report to count, that is a facts-struct change in one function.
</planner_assumptions>
