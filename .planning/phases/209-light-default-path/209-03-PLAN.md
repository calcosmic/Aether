<objective>
Shrink the default menu to about six commands and put everything else behind one machine-wide setting that the owner can switch on — without taking a single command away.

Purpose: D-02 and UED-18. The everyday menu is the first thing a person meets; twenty-two entries is why ordinary work feels heavy. Hiding is the whole change: nothing is removed, disabled or deprecated.
Output: `aether advanced-commands get|set <on|off>` storing the choice with the owner's preferences on his machine, a gated front-door renderer, the owner's ruling on the actual rendered screen, and a test that a hidden command still runs.
</objective>

    list back on screen whenever you want it. What has changed is only what you are shown first.
