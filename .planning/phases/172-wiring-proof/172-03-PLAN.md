<objective>
Bring the `.aether` markdown corpus into the flag audit, so an instruction that names a flag
the binary does not register fails CI with the file, the line and the flag.

`.aether/workers.md` is not in `auditedCorpora` at all — which is precisely why `--enforce`
has never been caught. Plan 172-00 already removed the second obstacle: before it, the
extractor could not see `result=$(aether …)` at all, so adding the corpus alone would have
produced a test that passes while the bug it exists to catch sits inside its scope. With the
extractor fixed in wave 1, this plan is the corpus addition, the drift it surfaces, and the
permanent proof that the whole chain bites.

Purpose: WIRE-03. Success criterion 3 says the test is "seeded to fail today against
`--enforce`, and it passes only once criterion 2 does". This plan runs after 172-01 so the
branch is never knowingly red; the seed is proven instead by a `git stash` transcript and by
a permanent fixture test that reproduces the pre-fix command shape on every CI run.
Output: A corpus that includes the top-level `.aether/*.md` files, a `.aether/workers.md`
whose every documented invocation actually works, and a fixture that keeps the proof alive.
</objective>
