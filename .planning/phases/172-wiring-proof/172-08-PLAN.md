inside guards this phase built or made load-bearing. Neither is exploited today; both are the

**Finding 1 — the extractor's two halves disagree.** `normalizeShellToken` strips three
substitution openers (`$(`, a backtick, and a bare `(`). `openedSubstitution`, which decides
whether to trim the *matching closing delimiter* off the last token, recognises only `$(`. So a
backtick substitution yields a command name carrying a trailing backtick and is dropped by the
name-shape check; `(aether status)` yields `status)` and is dropped; and `(aether status --json)`
is reported as a violation on a flag named `--json)` that nobody wrote. Verified by the reviewer
against a standalone reproduction. Zero live instances exist in the corpus today — which is
exactly why this would not be noticed until it produced a wrong answer, and the extractor is the
one component every other assertion in WIRE-03 reads the world through.

**Finding 2 — the flag audit no-ops when its input is missing.** `TestCLIFlagAudit` declares
three `..`-relative directories and `continue`s past an `os.ReadDir` error with no assertion. If
all three move, the loop reads nothing, `mismatches` stays empty and the test passes. It is named
in `.aether/docs/orphan-allowlist-policy.md:90` as one of the tests enforcing the policy, and
172-04 built the shrink-only skip-list guard on top of it — so a guard that can be switched off
by moving a directory is now load-bearing. Every other guard this phase added has an
anti-vacuity assertion; this one has none. It also reports failures by bare basename, and
`build.md` exists in both `.claude/commands/ant/` and `.opencode/commands/ant/` — so "naming the
file", which criterion 3 requires, is ambiguous today.

Purpose: WIRE-03 (extractor completeness) and WIRE-01 (D-12's skip-list guard rests on
`TestCLIFlagAudit` being non-vacuous).
