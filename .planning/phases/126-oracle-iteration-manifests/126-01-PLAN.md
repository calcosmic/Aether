## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TS host -> Go CLI | TS host passes completion files to Go; Go validates before writing state |
| Go CLI -> .aether/oracle/ | Go is the sole writer to oracle state files |
| User input -> completion file | Completion file path comes from CLI flag; must validate exists and is readable |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-126-01 | Tampering | completion-file path | mitigate | Validate file exists and is readable before parsing; reject paths outside tmpdir or in Go-owned dirs |
| T-126-02 | Information Disclosure | plan-only manifest | accept | Manifest contains no secrets; only oracle research state |
| T-126-03 | Denial of Service | malformed completion JSON | mitigate | Wrap JSON parse in error handling; return error envelope without crashing |
| T-126-04 | Elevation of Privilege | TS host writes to oracle dir | mitigate | TS host only calls Go commands; boundary enforced by go-bridge.ts `assertNoDirectDataWrites` and code review |
</threat_model>
