<objective>
Close the one genuinely unconnected wire in this phase: colony-prime's context
capsule never reaches a wrapper-spawned build worker. The hosted/subprocess path
already computes it once and shares it across dispatches
(`cmd/codex_build.go:1400`); the wrapper-facing manifest has no field for it at
all.

Purpose: this is the "grounding, not brevity" payload (D-01). A worker on a cheap
model does the right thing because it knows the colony's state, decisions, prior
learnings and blockers — not because its prompt is short.

Output: `codexBuildManifest.ContextCapsule`, computed once per plan-only
manifest, plus the two wrapper instructions that make the orchestrator actually
deliver it, plus a test that fails when either half stops working.
</objective>

| T-163-05 | Information Disclosure | manifest JSON written to a temp file outside `.aether/data/` by the wrapper | accept | Pre-existing wrapper behaviour for the whole manifest (briefs already contain the same class of content); the capsule adds no new secret class, and the file is local to the user's own machine. |
| T-163-06 | Tampering | wrapper reconstructing or summarising the capsule instead of passing it verbatim | mitigate | Both wrapper bullets state "verbatim, never reconstruct"; `TestBuildWrapperCeremonyContract` fails if the instruction is removed. |
