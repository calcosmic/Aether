<objective>
Fix the three places where Aether's instructions, permissions and schemas
disagree with each other, all of which were observed failing in the field.

A worker was told to write planning artifacts, was hard-blocked by a
`PreToolUse` hook, and routed around the guardrail with a scripted move
(`.aether/docs/known-issues.md`, 2026-07-28). A scout is dispatched with
`repository_read_only` permissions and a brief ordering it to write
`.aether/data/phase-research/phase-N-research.md`. A worker's `artifacts` schema
declares `additionalProperties: false` with zero properties, so the only legal
value is `{}`.

Purpose: a rule the system's own workers must evade protects nothing (D-04), and
instructions, permissions and schemas must agree (D-05).

Output: an exact-subpath allowlist in the real enforcement code, a scout
permission profile that matches its own brief, an artifacts schema with named
fields, and distributed rules text that tells the truth about all three.
</objective>
