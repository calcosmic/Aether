<objective>
The colony charter is generated at init, stored on `ColonyState`, and read by
nobody. `cmd/colony_prime_context.go` contains zero charter references, so a user
can approve "Linting: golangci-lint. Testing: pytest" and no worker ever learns
of it.

Purpose: governance the user approved should bind the workers who do the work
(CONTEXT-06), and the mechanically checkable part of it should be verified rather
than trusted (D-09). Silence is what made the charter decorative in the first
place.

Output: charter as one more `colonyPrimeSection` (inheriting the existing
prompt-integrity and ranking pipeline for free), plus a two-check charter
compliance gate wired into continue the same way the anti-pattern gate is.
</objective>

Five subtests pin the boundary. |
| T-163-08 | Repudiation | gate silently not running and being read as a pass | mitigate | Two-check producer copied from `checkAntiPatternGate`; `charter_compliance_executed` registered in `alwaysRunGates` so a skip cannot mask non-execution. |
