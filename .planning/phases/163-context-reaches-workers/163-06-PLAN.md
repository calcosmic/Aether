<objective>
`aether build <n> --print-brief` already exists and already works — it prints the
raw brief plus a composition table, unconditionally, with no comparison against
any budget. That is not what D-06 asks for. D-06 asks for a ten-second check: a
sectioned checklist saying which context arrived, how big each piece is, and
whether the total is sane, with raw text available on demand.

Purpose: this is the user's own verification window (CONTEXT-07) and the guard
that keeps every future context addition honest (CONTEXT-08, D-03). Because the
staged benchmark is descoped (D-08), the inspector plus the automated tests
across this phase ARE the phase's evidence — CONTEXT-09 is satisfied here or not
at all.

Output: a checklist-by-default inspector that knows what should be present, a
`--full` escape hatch, the first test coverage this command has ever had, and a
budget invariant that fails when assembled context outgrows its declared budgets.
</objective>
