<objective>
Give every kind of half-finished work one honest way of describing itself, and one place the owner can see all of it, so useful notes are kept without ever reading as settled results.

Purpose: Oracle already solved this for its own partial research — a standing label, applied consistently, that says what a document is and is not. The failure mode this phase must avoid is solving it three more times, once per subsystem, with three different words for the same idea. That is the drift this repository has paid for repeatedly. One vocabulary, applied to Swarm's unproven repair ideas, Oracle's partial research, plan research and local reflections, is both less code and the only version that stays true.
Output: `cmd/partial_work_label.go` holding the shared standing vocabulary and the inventory of unverified work, with Swarm and Oracle both drawing from it.
</objective>
