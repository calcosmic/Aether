<objective>
Fill the middle branch of the watch command: when nothing is running but something has run, show a replay-backed summary of the most recent episode rather than an idle card that pretends nothing ever happened.

Purpose: Phase 199 deliberately made `watch` permanently idle and wrote the reason into the code — no typed event source existed yet with liveness semantics. This phase supplies that source, and the idle card's honesty is exactly what must survive the change: it stays as the floor for a colony with no history, while a colony that has run something gets the truth about the last thing it did. The rule that separates the two is the one Phase 199 established and this plan must keep: a recorded row is evidence, never a claim that an ant is working right now.
Output: `cmd/watch_replay.go` holding the replay-backed summary, wired as the second of the three branches, with the idle floor and its tests unchanged in meaning.
</objective>
