<objective>
Make one Swarm run leave exactly one durable, replay-safe episode that carries everything the run learned and did, governed by retention rather than by a directory sweep.

Purpose: The run already persists a result record, and strike counting already reads it — that part works and must not be disturbed. What does not exist is the rest of the story: which lenses ran, what each concluded, what the comparison decided, whether the checkpoint was restored, what it cost, and whether the whole thing was interrupted partway. Without that, status and history have nothing to point the owner at, and the first cleanup mechanism anyone writes ends up deleting by directory prefix — which is exactly how the wrong thing gets removed.
Output: `cmd/swarm_episode.go` holding the episode, its retention metadata and its learning proposal, bound to the existing result record rather than replacing it.
</objective>
