measured/estimated split, the parent attribution, and the no-double-count invariant that make

"the field exists".

Output: `cmd/spend_ledger.go` with the record types, save/load, totals, roll-up and the
`--include-estimates` gate; `cmd/spend_ledger_test.go` proving each.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `.aether/data/spend/phase-N-<workflow>.json` → `loadSpendLedger` | An on-disk colony file; malformed or version-mismatched content must degrade, never crash |
| one workflow's ledger → the other workflow's ledger | Writing a continue must never reach the build's file, or a phase loses the run that cost the most |
| ledger rows → reported totals | The point where an estimate could be laundered into a measurement |
