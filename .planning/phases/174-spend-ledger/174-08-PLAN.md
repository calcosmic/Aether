<objective>
Put the number where the operator will actually meet it: one plain-English line at the end of every
build and every continue, sourced from the ledger, leading with tokens.

Purpose: D-03 and SPEND-08. A non-technical operator does not run inspection commands. Without this
line the whole phase is a dashboard nobody opens. `renderCeremonyCloseoutVisual` is a single shared
function invoked by both `build.md` and `continue.md` through `aether ceremony closeout --workflow`,
so one change reaches both surfaces — and duplicating the logic in wrapper prose would violate the
UX ownership rule that wrappers present and never compute.

Output: the ledger read added to `renderCeremonyCloseout`, a `writeCeremonySpendLine` formatter
called from `renderCeremonyCloseoutVisual`, and tests covering build, continue, mixed and absent.
</objective>
