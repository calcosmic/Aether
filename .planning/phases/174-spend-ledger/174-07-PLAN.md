## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `.aether/data/spend/phase-N.json` → report render | An on-disk colony file rendered to a human; malformed content must degrade, never crash |
| runtime figures → wrapper markdown | The wrapper may present but never compute; a wrapper-computed figure would reintroduce the assertion problem D-06 rejects |
| inspection command → colony state | The boundary CLAUDE.md's dry-run corollary governs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-174-25 | Tampering | `spendCmd` write path | mitigate | The command has no write call at all, asserted by a grep returning 0, and `TestSpendCommandIsIdempotent` hashes seven watched files before and after two runs |
| T-174-26 | Repudiation | vacuously-green purity test | mitigate | `TestSpendPurityHarnessDetectsAMutation` proves the hashing harness observes a real change, mirroring `TestConsolidationRealRunStillMutates` |
| T-174-14 | Spoofing | estimate rendered as measurement | mitigate | Measured and estimated print on two separate lines, the per-worker average is refused by name over a mixed ledger, and each row prints its source in translated plain words |
| T-174-27 | Spoofing | invented money figure | mitigate | No price table, no token-to-dollar arithmetic (grep returns 0), and USD prints only when a provider row reported one, labelled as a hypothetical API price |
| T-174-28 | Denial of service | oversized ledger render | accept | The ledger's row count is bounded by a phase's dispatch count (single digits to low tens); no additional bound is warranted |
| T-174-15 | Information disclosure | task text on screen | accept | The task line is the same one-line description already printed during the build and stored in `spawn-tree.txt` |
