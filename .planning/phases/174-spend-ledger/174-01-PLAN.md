<objective>
Give `WorkerUsage` a third, honest source tier for platform-harness measurements, expose the
two totals the spend report must display without letting anything restate the arithmetic, and
stop the direct-dispatch path from discarding a provider measurement it already holds.

Purpose: Every later plan in this phase reads and tags usage. If the tagging vocabulary and the
total arithmetic are not fixed first, each downstream parser invents its own — which is exactly
how the 186x undercount shipped green the first time.

Output: `pkg/codex/usage.go` gains `UsageSourceSessionTranscript`, `Estimated()`,
`BilledTotalTokens()` and `TotalInputTokens()`; `internalWorkerResult` carries `Usage` and
`mapInternalWorkerResult` copies it through.
</objective>

    type WorkerUsage struct {
        InputTokens         int64   `json:"input_tokens,omitempty"`
        CachedInputTokens   int64   `json:"cached_input_tokens,omitempty"`
        CacheCreationTokens int64   `json:"cache_creation_tokens,omitempty"`
        OutputTokens        int64   `json:"output_tokens,omitempty"`
        TotalTokens         int64   `json:"total_tokens,omitempty"`
        USDCost             float64 `json:"usd_cost,omitempty"`
        Model               string  `json:"model,omitempty"`
        Source              string  `json:"source,omitempty"`
    }

    func (u WorkerUsage) Measured() bool   // == (Source == UsageSourceProvider)
    func (u WorkerUsage) Empty() bool
    func (u WorkerUsage) billedTotal() int64   // unexported today
    func EstimateUsage(promptChars int) WorkerUsage
    func ParseUsage(rawOutput string) (WorkerUsage, bool)

    const (
        UsageSourceProvider = "provider"
        UsageSourceEstimate = "estimate"
    )

`Measured()` has NO production callers today — its only three call sites are in
`pkg/codex/usage_test.go`. Widening it would be invisible and therefore dangerous; this plan
deliberately leaves its meaning alone.

`pkg/codex/worker.go` already declares `WorkerResult.Usage WorkerUsage`, and
`pkg/codex/platform_dispatch.go`'s `AttachWorkerUsage` already populates it on every real
dispatch. The break is downstream, in `cmd/internal_worker_adapter.go`.
