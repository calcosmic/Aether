<objective>
Resolve the two accounting paths into one authoritative token type before
anything renders a cost.

Purpose: the chat-model client's usage value carries only input and output —
no cache columns at all — and the agent pool reports exactly those two. That is
the same shape as the 186x undercount already in this repository's history,
alive on a second lane. Displaying a cost line while two sources disagree
produces a number nobody can trust, which the owner has said is worse than no
number.
Output: four billed columns on the client usage value, one conversion into the
authoritative worker usage type, and a cross-path equality invariant.
</objective>
