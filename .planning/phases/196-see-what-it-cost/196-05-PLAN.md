<objective>
Salvage the OpenCode reader, join it to the Claude reader behind one resolver,
and write the run's rows into the ledger from the build finalize path.

Purpose: today nothing on the chat path the owner actually uses produces a usage
figure at all, and nothing anywhere writes a single ledger row. This plan closes
both gaps in one change, because merging the reader without wiring it would
recreate this repository's named signature failure: code that works and that
nothing calls.
Output: the fixed reader, one resolver, and a build that leaves per-worker rows
on disk.
</objective>

the session record's path check and the reader's store path check call it. Two
copies of a security boundary is one copy too many, and the salvaged branch added
a symlink-evaluation helper without refactoring the original to use it.

Apply FIX 2-4: replace the check-then-read pattern with an open-then-limit read,
closing the gap between the size check and the read. Same amount of code, no gap.
