<objective>
Make finish-and-archive complete on its own, and stop the finalize command from writing human text into a machine-readable stream. Both are on the owner's very first journey.

Purpose: a real run on another project on 2026-09-14 found that returning to work deletes the hand-off note, the seal never rewrites it, and the archive then refuses to run because the note is gone. The same report found the finalize command printing its human card into the stream a wrapper parses as pure JSON. Both are confirmed still open.

Output: an archive that can synthesise its own stand-in note, a return-to-work path that leaves a usable note behind, and a finalize command whose machine output is machine-only.
</objective>
