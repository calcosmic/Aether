Read the mandatory section list from the template file itself — parse its top-level numbered headings — rather than typing the eight names into the test. If the template changes, the audit must change with it.

Create these functions:
- `classicSynthesisArtifactPaths(root string) ([]classicSynthesisArtifact, error)` — returns the seven artifacts in ascending phase order (199, 200, 201, 202, 202.1, 203, 204), each carrying its phase label and its file path. A phase directory that exists but carries no synthesis artifact is an error naming the phase, never a skip.
- `classicSynthesisMandatorySections(root string) ([]string, error)` — parsed from the template.
- `auditClassicSynthesisSections(path string, mandatory []string) ([]classicSynthesisFinding, error)` — for each mandatory section, report present-with-content, present-but-empty, or absent. Matching is on the normalised heading text: lowercase, whitespace-collapsed, punctuation-trimmed, and an exact match — a heading that merely contains the section's words does not count. Present-but-empty means the heading exists with no non-blank, non-heading line before the next heading of the same or higher level; it is reported as a failure of the same weight as absent.

Write `TestClassicSynthesisPhase203HasEveryMandatorySection` first, asserting Phase 203's artifact reports every mandatory section present with content. Run it before writing the audit functions so the failure is a real red, then make it pass.

Add `TestClassicSynthesisAuditRejectsAMissingSection` and `TestClassicSynthesisAuditRejectsAnEmptySection`: build two temporary copies of a real artifact — one with a mandatory heading removed, one with its body emptied — and assert each produces a finding naming the artifact and the section. Operate on temporary copies; never modify a real artifact.

Add `TestClassicSynthesisSectionMatchIsExact`: a temporary copy whose heading is a longer sentence containing a mandatory section's words is reported as absent.
  </action>
