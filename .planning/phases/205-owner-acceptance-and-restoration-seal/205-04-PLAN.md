<objective>
Make the seal and archive wrappers tell the truth about who reviews a seal, and make the runtime's card actually reach the owner in Claude Code.

Purpose: this is capability row CAP-023 — documentation accuracy checked against real public behaviour — and it is the only Phase 205 row routed to PROOF-03. The seal wrapper states a flat three-worker review roster; the runtime derives the roster from the project's own state, its depth and named risk signals, so the claim is wrong for an ordinary project. Separately, the seal and archive wrappers run the runtime in its picture-drawing mode through a shell and never tell the assistant to show what came back, so the owner sees nothing.

Output: corrected wrapper text in all three copies per command, a relay instruction, and a check that fails if wrapper and runtime drift apart again.
</objective>
