## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| continue advance → colony state files | Consolidation mutates `instincts.json`, `learning-observations.json`, and `.aether/QUEEN.md` immediately after a phase advance commits |
| consolidation failure → operator | The only signal that learning did not happen is the stderr line |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-162-10 | Tampering | Partial consolidation failure leaving `instincts.json` half-decayed while `COLONY_STATE.json` already says the phase advanced | mitigate | Consolidation runs strictly AFTER the atomic `COLONY_STATE.json` write, so a consolidation crash can never corrupt the phase-advance record; pkg/memory writes each store file via `store.SaveJSON`/`AtomicWrite` (temp file plus rename) so no file is left truncated. `TestRunPhaseEndConsolidationIsNonBlockingOnFailure` pins the non-abort behaviour. |
| T-162-11 | Denial of Service (soft) | A curation sentinel abort (corrupt stores detected) being reported as a generic failure and ignored | mitigate | Task 1 requires the D-05 warning to name a sentinel abort specifically, so store corruption is distinguishable from a transient error in the one line the operator sees. |
| T-162-12 | Denial of Service | A wedged or very slow consolidation blocking every phase advance | mitigate | Task 1 requires a bounded `context.WithTimeout` rather than `context.Background()`; on timeout the D-05 warning fires and the advance proceeds. |
| T-162-13 | Repudiation | Consolidation silently not running, reproducing the four-milestone "declared restored, never called" history | mitigate | Three wiring tests including a negative case (Task 2) plus a beat that prints in all four states including absent (Task 3). Silence is not a reachable output. |
