<objective>
Make the consolidation pipeline's promotion destination reachable before anything
starts calling it.

Purpose: this is the load-bearing discovery of Phase 162 and it is not in
RESEARCH.md. `pipelineConfigForStore()` sets `QueenPath: "QUEEN.md"`, which
`storage.Store.resolvePath` joins onto the store base — so `pkg/memory`'s
`QueenService.PromoteInstinct` writes to `.aether/data/QUEEN.md`. Colony-prime
reads `~/.aether/QUEEN.md` and `.aether/QUEEN.md` only (cmd/colony_prime_context.go
:726 and :752). Worse, `readQUEENMd` (cmd/context.go:1528) ingests only the
Wisdom / Patterns / Codebase Patterns / Philosophies / Anti-Patterns sections —
never `Instincts`, which is the only section `PromoteInstinct` writes to.

The promotion target is therefore double-dead: wrong file, and a section no reader
consumes. Wiring consolidation into the lifecycle (plans 03 and 04) without fixing
this would switch learning on into a void — precisely the failure mode CLAUDE.md's
Definition of Done exists to prevent, and the reason the learning pipeline has been
"declared restored" four times already.

Output: one resolved promotion path, an Instincts section that exists and is read,
proof that a promoted instinct reaches a worker's prompt, and dry-run purity
extended to cover the relocated file.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-162-06 | Tampering | `ensureQueenInstinctsSection()` rewriting an existing user-authored QUEEN.md | mitigate | Append-only at end of file; `writeLocalQueenText` already refuses empty writes; Task 1's acceptance criterion requires pre-existing lines preserved byte-for-byte and idempotence on a second call. |
| T-162-07 | Information Disclosure | Widening `readQUEENMd`'s allowlist could pull unintended sections (User Preferences, Colony Charter) into worker prompts | mitigate | Exact-match plus prefix term for `Instincts` only; Task 2's acceptance criterion requires a test confirming preferences and charter lines are still excluded. |
| T-162-08 | Denial of Service (soft) | Consolidation writing to `.aether/QUEEN.md` concurrently with `promoteInstinctLocal`'s plain `os.WriteFile` — a lost update | accept | `store.AtomicWrite` takes a file lock; `writeLocalQueenText` does not. Both run single-threaded inside one lifecycle command today, and plan 04 removes the overlap at seal by deduplicating the writers. Recorded so the residual risk is deliberate. |
| T-162-09 | Tampering | Prompt-injection text reaching workers via a promoted instinct's Action field | accept | Instinct Action text already reaches workers today through the `## Active Instincts` section, which reads `instincts.json` unconditionally. This plan changes the route, not the exposure. Out of scope per REQUIREMENTS.md Non-Goals. |
