<objective>
Make the Hive Brain on by default through exactly one control surface, and retire
the consent-file gate that silently vetoed it.

Purpose: LEARN-04 is decision-shaped. The user's decision (D-01/D-02) is "on,
full, one switch." Today `currentHiveRuntimePolicy()` defaults to `off` AND a
second undocumented-in-CLAUDE.md consent file must exist before retrieval works
— a double gate where the second one silently overrides the first. This plan
makes the documented behaviour the real behaviour.

Output: promote-by-default policy resolution, explicit `off` preserved,
fail-safe handling of typos, the consent file and its two cobra commands gone,
and AGENTS.md telling the truth.
</objective>

| `~/.aether/hive/wisdom.json` → worker prompt in another repo | Text authored elsewhere is injected into a model prompt in this repo |
| operator env → runtime policy | `AETHER_HIVE_POLICY` is the sole control over both directions |
