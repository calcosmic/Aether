<objective>
Integrate PlaybookLoader into the TS host ceremony flow for build and plan commands.

Purpose: This plan makes the TS host the single conductor for Claude/OpenCode build and plan workflows (CEREMONY-04). The host.ts runDispatchedBuildCommand and runDispatchedPlanCommand functions load playbook files, inject their content into worker briefs as document-injection (CEREMONY-06), and sequence ceremony adapter calls at the timing dictated by playbook awareness (CEREMONY-05). The existing ceremony adapter calls (renderSpawnPlan, renderWaveStart, renderWorkerComplete, renderCloseout) remain unchanged -- Go still owns visual rendering. The change is additive: playbook content is loaded and injected into dispatch task_briefs, and the host gains awareness of which playbook step it is executing.

Output: host.ts with playbook-aware ceremony flow, updated tests.
</objective>
