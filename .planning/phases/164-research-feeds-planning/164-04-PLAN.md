<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user goal text -> granularity reason | The colony goal is user-authored free text and is measured (word count) to pick a reason |
| user selection -> depth flags | The chosen option values become CLI flag arguments on a later `aether host plan` invocation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-164-10 | Tampering | `renderGranularityReason` | mitigate | The goal is only measured (`strings.Fields` word count) and never interpolated into the reason string; reason text comes solely from the `granularityReasons` lookup table with numeric values formatted in |
| T-164-11 | Tampering | depth values reaching CLI flags | mitigate | The card only ever emits values drawn from the fixed option sets (sprint/milestone/quarter/major, light/standard/deep, light/standard/heavy); the downstream `resolvePlanningDepthSmart` / `resolveVerificationDepthSmart` already reject unknown values, which is the V5 input-validation control named in 164-RESEARCH.md's security domain |
| T-164-12 | Spoofing | card presenting a recommendation the runtime did not compute | mitigate | Every recommendation and reason is produced by Go (`computeDepthProposal`) and rendered by Go (`renderDepthProposalCard`); Plan 09's wrapper is required to print the runtime string rather than compose its own, per the wrapper-runtime UX contract |
</threat_model>
