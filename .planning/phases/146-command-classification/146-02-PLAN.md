# Plan 146-02: Implement `aether audit-catalog` CLI Command

**Objective:** Build a CLI command that reads the enriched catalog and outputs both human-readable (markdown) and machine-readable (JSON) classification reports.

## must_haves

- `aether audit-catalog` runs without errors and outputs a classification report
- Output includes every command with its classification and since_version
- Machine-readable JSON output is available via `--json` flag
- Human-readable markdown table is the default output

## tasks

### Task 1: Implement audit-catalog command

<read_first>
- cmd/testdata/command_catalog.json
- cmd/audit_catalog.go (if exists, or nearest audit-related command)
- cmd/root.go or main.go (for command registration pattern)
</read_first>

<action>
Create `cmd/audit_catalog.go` that:
1. Registers `audit-catalog` as a top-level command under the `aether` CLI
2. Reads `cmd/testdata/command_catalog.json` at runtime (using embed.FS or relative path resolution)
3. Groups commands by classification
4. Default output: markdown table with columns `Command`, `Classification`, `Since`, `Description`
5. With `--json` flag: outputs JSON array of `{name, classification, since_version, short_description}`
6. With `--format {markdown|json|csv}` flag: selects output format (markdown default)
7. Exit code 0 on success, 1 if catalog file cannot be read
</action>

<acceptance_criteria>
- `go build ./cmd/aether` succeeds with the new file
- `aether audit-catalog` prints a markdown table with all 389 commands
- `aether audit-catalog --json` prints valid JSON array
- `aether audit-catalog --format csv` prints comma-separated values
- Command fails gracefully if catalog JSON is missing or malformed
</acceptance_criteria>
