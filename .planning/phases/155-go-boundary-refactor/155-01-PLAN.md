In `cmd/visuals_config.go`:
1. Define `type visualsConfig struct` with fields matching the YAML frontmatter (use `yaml` tags).
2. Define `var loadedVisuals *visualsConfig` and `var visualsOnce sync.Once`.
3. Implement `func loadVisualsConfig() *visualsConfig` that:
   - Looks for `colony/ceremony/visuals.md` relative to the working directory (the repo root).
   - If found, reads the file, extracts YAML frontmatter (text between first `---` and second `---`), and unmarshals into `visualsConfig`.
   - If file missing, unreadable, or unparseable, returns `nil` (fallback path).
   - Caches the result via `sync.Once` so file is read at most once per process.
4. Implement helper accessors:
   - `func fileCasteEmoji(caste string) (string, bool)`
   - `func fileCasteColor(caste string) (string, bool)`
   - `func fileCasteLabel(caste string) (string, bool)`
   - `func fileCommandEmoji(command string) (string, bool)`
   - `func fileCastePrefixes(caste string) ([]string, bool)`
   - `func fileAetherWordmark() (string, bool)`
   - `func fileVisualDivider() (string, bool)`
   Each returns the value + true if loaded config has it, else ("", false).

In `cmd/codex_visuals.go`:
1. Replace direct map lookups in `casteEmoji()`, `casteLabel()`, `casteANSIColor()`, `commandEmoji()` with "file first, fallback to hardcoded" logic.
2. Replace `aetherWordmark` constant usage in `renderAetherWordmark()` with "file first, fallback to constant".
3. Replace `visualDivider` constant usage similarly.
4. Replace `castePrefixes` / `defaultPrefixes` usage in `deterministicAntName()` with "file first, fallback to hardcoded".

    if emoji, ok := casteEmojiMap[caste]; ok {
        return emoji
    }
    return "🐜"
}
