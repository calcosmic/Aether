# Phase 163.2 Plan 02: Shared Go Provider Preflight Runner Summary

**Codex's preflight probe now runs through the same shared timeout/retry runner as Claude and OpenCode, and every Go provider probe executes in a throwaway `aether-preflight-*` temp directory instead of the repo working tree.**

## Accomplishments
- Deleted the Codex probe's own inline `20*time.Second` context and `exec.CommandContext` call; `RealInvoker.Preflight` now calls the same `runHostedProviderPreflight` shared runner Claude and OpenCode already used, so it inherits `AETHER_PREFLIGHT_TIMEOUT` and the one-retry-on-timeout policy for free
- Moved the probe's working directory from the repo root (`cmd.Dir = root`) to a fresh `aether-preflight-*` temp directory created through a swappable `makePreflightTempDir` seam, cleaned up with `defer os.RemoveAll` after every attempt
- Made the temp-dir failure path degrade safely (leaves `cmd.Dir` unset, probe still runs) instead of bricking dispatch, and proved it with a forced-failure test
- Added five new invariant tests, each manually mutation-tested against its specific regression (temp-dir wiring removed, hardcoded 20s timeout reintroduced, probe prompt changed, temp-dir failure converted into an early return) and confirmed to fail before being reverted to the correct implementation
