<objective>
Grow the tracer's minimal intent into the full BIO-01 wire shape, with a validator that refuses by name and a durable intent record written before any decision is taken.

Purpose: the tracer proved the path; this makes the thing travelling down it complete and trustworthy. Every field BIO-01 names is a field the admission gate in plan 203-06 will need, and a field a later reader — status, watch, recovery, cost — will need to explain what was asked for. Getting the shape right once here is what stops plan 203-06 inventing its own parallel input struct.
Output: a complete, versioned, validated, sanitised, durably recorded recruitment intent.

Flagged planner assumption (unresolved edge probe, BIO-01, category `unclassified`): BIO-01 lists "cost limits" without a unit. This plan rules the unit to be helper slots against the existing whole-run tree budget plus a wall-clock second count, because D-12 forbids a separate recruit allowance and because Phase 196 already established that an unread currency field on a shared struct is a standing hazard. If a later reviewer intended money, this ruling is wrong and plans 203-03, 203-06 and 203-14 all change. Surfaced, not resolved.
</objective>
