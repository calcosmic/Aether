<objective>
Make one function the only answer to "is this note in effect, how strongly, and until when" — and give every note a recorded origin, with anything arriving from another project held back until the owner lets it in.

Purpose: the write side of this system is already singular and well behaved. The read side is not: one reader filters on active-and-strong but never checks expiry, another checks expiry too, and a third uses a different strength floor entirely. One of the files involved already carries a comment observing that two of these disagree. That divergence is why a note can be visible on one screen, absent from a worker's brief, and still counted somewhere else. BIO-07's real work is on the read side, plus the provenance the quarantine rule in D-10 needs to exist at all.
Output: one resolver, one predicate, recorded provenance, and a quarantine state that only an owner can clear.

Flagged planner assumption (unresolved edge probe, BIO-07, category `unclassified`): BIO-07 says cross-project input "starts quarantined" without saying what quarantine excludes it from. This plan assumes quarantine excludes a note from worker briefs, from decision influence, and from strength tuning, while leaving it visible in listings and in the approval queue — because a quarantined note nobody can see could never be released. Surfaced, not resolved.
</objective>
