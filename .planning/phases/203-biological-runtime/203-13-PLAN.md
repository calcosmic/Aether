<objective>
Let outcomes move a note's strength — up when it demonstrably helped, down when it demonstrably did not — while keeping every movement traceable and every owner decision untouchable.

Purpose: this is the one part of the phase the owner has already rated costly, and the reason is precise: once strengths start moving on their own, telling a learned strength apart from one the owner set becomes hard, and freezing the system later means untangling the two. What makes it undoable is the immutable history built in plan 203-11, and the rule that an owner-pinned note is never touched. Both must be in place and proven before a single number moves automatically.
Output: outcome-weighted tuning with automatic quarantine, driven only by recorded credit, never by delivery.

Reversibility: **costly** — carried directly from the owner's own rating on D-09. Freezing automatic tuning later requires separating learned strengths from owner-set ones; the immutable action history with a recorded actor on every entry is exactly what makes that separation possible, so it is a prerequisite of this plan rather than a companion to it.
</objective>
