<objective>
Make the Go gate the only thing in this program that decides whether a helper may be started — on the autopilot lane as well as the interactive one — and delete the second budget counter that has been quietly deciding it on one of them.

Purpose: this is the single most load-bearing correction in the phase. A complete, correct-looking spawn policy engine exists in TypeScript with its own twenty-slot budget and its own depth-two constant, and it is live: the host constructs it, threads it through the build wave into the worker dispatcher, and the wave orchestrator calls it and dispatches the children it accepts. Nothing in that path ever asks Go. Two independent counters for one safety limit is exactly the condition this phase exists to end, and fixing it by calling the existing engine "correctly" would entrench it.
Output: one authority, one counter, one reason vocabulary, across both lanes.

Flagged planner assumption (carried from the BIO-02 unclassified probe, recorded in plan 203-06): "parent authority" is taken to mean a recorded, non-terminal spawn-tree entry. On this lane the parent is the manifest worker, whose entry the build already records, so the assumption holds identically here. Surfaced, not resolved.
</objective>
