<objective>
Record what actually happened to a piece of remembered guidance — shown, read, used, ignored, argued with, and whether using it helped, did nothing, or hurt — instead of recording a success every time a phase finished.

Purpose: the current mechanism proves one thing well and nothing else. It proves an instinct's text was genuinely present in what a worker received, which is a real advance over assuming injection. It then records a success for every one of them on any phase that advanced, because reaching that code means the phase advanced. There is no code path anywhere in this system that records a failure, an ignore, or a contradiction for a piece of guidance. A memory system whose feedback signal can only ever say "it worked" is not learning; it is accumulating.

Output: nine declared states with a transition rule, worker claims independently checked, and a promotion gate that requires a lesson to have actually helped at least once.
</objective>

## Planner Assumptions (no CONTEXT.md — owner may veto)

**Assumption K (Research Open Question 4's sibling; edge probe LEARN-03, unclassified — surfaced, not resolved) — a helper saying "I used that" is a claim, not a fact.**
When a helper says it read or followed a piece of remembered advice, the program checks that against what it can see for itself — the files that changed, the decisions the helper recorded — before it counts. A claim it cannot check is written down as an unchecked claim, which is neither believed nor thrown away.
*If the owner disagrees* (wants helpers believed): the old system did exactly that and this project's own rules already treat helper self-reports as untrusted input, re-running their claimed evidence rather than accepting it.
*If a later reviewer disagrees about what counts as checkable:* the affected work is this plan.

**Assumption L — "ignored" is something we write down, not something we leave blank.**
Advice that was put in front of a helper and then not used is recorded as ignored. That is the single most useful signal this system currently throws away, because it is what should make weak advice stop being shown.
