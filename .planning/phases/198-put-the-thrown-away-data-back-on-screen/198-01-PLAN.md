<objective>
TRACER SLICE. Prove the whole SHOW-01 architecture end-to-end on one workflow: make the
chat-path closing screen for `continue` come from the *same* renderer the direct
command-line path uses, fed by the completion file's own whole result — and lock it with a
real parity test.

Purpose: this is the structural fix D-12 demands. Today the chat path re-derives a much
thinner result map (`closeoutCompletionDetails`, ~15 of 20-40 keys) and renders it with a
second, narrower renderer (`renderCeremonyCloseoutVisual`). Every SHOW-02 item that is
"already carried but never shown" dies at that seam. Fixing the seam once, for one
workflow, proves the architecture before plans 04-09 expand across it.

Output: `cmd/closeout_direct_render.go` (the bridge), the `continued_phase` /
`continued_phase_name` additions the bridge needs, and
`TestWrapperPathRendersSameCeremonyAsDirectPath` passing for the `continue` workflow.
</objective>

   - `closeoutDirectVisual(workflow string, result map[string]interface{}, state colony.ColonyState) (string, bool)` — returns the direct-path render and `true` when it handled the workflow, `("", false)` otherwise.
