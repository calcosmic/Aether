## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Tests that install into the real home folder | On 2026-10-02/03 the owner's installed `~/.local/bin/aether` was replaced twice by builds of the checkout under test. The second time was a *targeted* `-run 'Run\|...'` group in the main checkout, which happened to match the practice-project test. That test's script installed the program and command files into the real HOME. Fixed in 149bce88. | blocking | Hash `~/.local/bin/aether` before and after any test run that builds or installs. Run full suites in a throwaway worktree with `HOME=<scratch>/suite-homeN` (pre-create `.local/bin`), `GOPATH`/`GOMODCACHE`/`GOCACHE` set explicitly, and `GIT_AUTHOR_*`/`GIT_COMMITTER_*` env vars. |
| Committing during a full suite | The protected-inputs check (`TestPlanningAdversarial200`) snapshots git refs, and a gate worktree shares refs with the main checkout. Commits made mid-suite turned it red. | blocking | Make no commits while a suite runs. Prepare edits, then commit after the suite finishes. |
| Building a fix on an unverified symptom | WINDOWS 77 was first written from a chat's warning, not a reproduction. The first replay did not loop. Only a faithful fixture (phase BUILT, check stopped after the build, not paused) showed the loop. | advisory | Reproduce with the owner's exact shape before fixing. Probe tests are temporary and never committed. |
| `git checkout -- <file>` to undo a deliberate mutation | Wiped this session's uncommitted handover code. | advisory | To prove a test can fail, copy the file to scratch, mutate it, run the test, then restore from the scratch copy. |
| Look-alike names on macOS | A worktree folder and a binary named `Aether-prefix` and `aether-prefix` collide on the case-insensitive filesystem. | advisory | Use clearly different names for scratch folders and files. |
