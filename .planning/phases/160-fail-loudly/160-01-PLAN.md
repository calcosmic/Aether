Read the live files first and match the actual value types you find — do not
assume `int` where the file holds a float or string.

- `model_routing.default_provider` (string, value `anthropic`)

- `pheromone_lifecycle.default_ttl_days`, `pheromone_lifecycle.max_active_signals`, `pheromone_lifecycle.strength_decay_per_day` (numeric), `pheromone_lifecycle.auto_expire_on_phase_end` (bool)
