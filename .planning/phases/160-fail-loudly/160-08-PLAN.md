<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Go-emitted guidance → user action | Recovery text the runtime prints is instruction a user follows; naming a nonexistent command strands them mid-recovery after a gate failure |
| wrapper markdown → shell execution | The new wrapper becomes literal prompt text an LLM turns into an `aether unblock` invocation; it must not carry its own state-mutating logic |
| repository → local hub (`~/.aether/`) | `aether publish` copies companion files across this boundary for downstream repos |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-160-26 | Elevation of Privilege | A wrapper reimplementing gate recovery and marking gates resolved without the Go gate pipeline agreeing | mitigate | The wrapper routes to `aether unblock` only; a guardrail in `unblock.yaml` prohibits reimplementing recovery or Fixer dispatch; the plan forbids any diff to `cmd/unblock_cmd.go` |
