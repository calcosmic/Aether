<objective>
Close the test blind spot that let seven broken CLI calls survive: build an audit
that validates positional-argument shape and verifies a curated subset by
execution rather than regex, and encode D-01's gate-versus-enrichment
classification where that audit can assert it.

`cmd/cli_flag_audit_test.go` was verified line by line during research. Its outer
regex captures only a trailing run of `--flag` tokens, so for a line like
`aether skill-detect "$(pwd)"` the flags group matches zero repetitions, the
positional argument is invisible, and the test passes. It never consults
`cmd.Args`. That is the whole blind spot, in one sentence.

`cmd/security_gate_drift_test.go` is the only execution-based precedent in the
repo: it drives `rootCmd.Execute()` against a temp fixture and asserts exit code,
stderr and parsed envelope. This plan generalises that shape.

D-01 requires every audited call to be classified gate or enrichment, "encoded
where the audit can test it". RESEARCH.md Open Question 3 resolves the scope:
`check-antipattern` is the only genuine safety gate among the seven; the other five
are enrichment calls with no live gate call site. The classification still gets
written down and asserted, because an unwritten classification is exactly the kind
of claim this phase exists to eliminate.

Purpose: LOUD-04, LOUD-05, decision D-01, and ROADMAP success criterion 3.
Output: a classification file and one audit test covering three requirements.
</objective>

arguments.

**Classifying tokens.** For each token decide: flag (starts with `--`), flag value
(follows a flag that takes a value — approximate by treating the token after a

positional. Treat placeholder tokens as positionals: `$ARGUMENTS`, `$1`,
`{something}`, `<something>`, `"$var"`. Placeholders that stand for a whole
argument vector are the one real ambiguity — for `$ARGUMENTS` specifically, count
it as an unknown-arity placeholder and skip the arity assertion for that call while
still asserting the subcommand and any explicit flags exist. Record that decision
in a code comment so a later reader does not think it was an oversight.

registered `*cobra.Command`, build a synthetic args slice of that length, and
invoke `cmd.Args(cmd, syntheticArgs)` directly — `cobra.PositionalArgs` is
`func(cmd *Command, args []string) error`, so this needs no reflection. A non-nil
return is a violation. Report file, line number, the offending call text, the
positional count, and the validator's error message. Also keep the existing flag
check: every `--flag` must be registered on that subcommand or one of its aliases.

PATTERNS.md flags this specific sub-piece as new design, so budget for it rather
than expecting a copy job.

commented skip list. Report unclassified subcommands as a distinct failure category

`cmd/command_call_severity.go`.

live wrapper directories only; the dead corpora are audited for contract
correctness, not for stderr behaviour.
