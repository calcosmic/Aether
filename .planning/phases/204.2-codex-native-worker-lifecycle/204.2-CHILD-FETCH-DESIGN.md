## Protocol and authority

- New accepted native manifests and worker bindings pin `child-fetch/v1`. Missing protocol retains historical host-send semantics; existing attempts cannot switch in place.
- The existing read-only `codex-native-worker context` operation gains an explicit initial/answers purpose. Initial returns the exact saved full prompt; answers uses the existing current-question/current-assignment renderer. A versioned envelope binds purpose, protocol, payload bytes, decision IDs and all existing assignment identities.
- A separate child `context-ack` operation validates the delivery ID and payload hash obtained from that completed read. It rechecks currency and returns a typed acknowledgement. Reads and ACKs do not mutate journals or award credit.
- The parent records an explicitly typed fetch observation containing both actual child source identities. It cannot manufacture a successful legacy send. The existing Go journal and finalizer retain delivery and completion authority.
- Child order is completed read, separate successful ACK, then relevant work/checks. Parent observation may occur after work, but must precede acceptance of successful terminal results. This avoids a new blocking handshake. The source timestamps must still prove ACK preceded the work; record time is not substituted for source time.
- New-protocol successful terminal acceptance requires its initial delivery receipt and applicable answer receipts. ACK alone proves neither implementation, checks, termination nor completion credit.

## Rejection and compatibility

Preserve the exact 2 MiB encoded request bound, Unicode/whitespace equality, delayed challenge generation, scoped answer authority, refusal on stale/wrong-child/cancel-pending state, unchanged rejected journals, recovery uncertainty and exactly-once finalization. The request bound is not a promise that the host can deliver a 2 MiB output: truncation must fail proof rather than silently trim instructions.

Actual evidence must contain the complete Go output returned to the intended child, corroborated against its command event and pinned candidate. Parent execution, copied stdout, reconstructed prompts, digests without plaintext, ciphertext, failed/truncated commands, reused ACKs, wrong turns/workspaces and ambiguous duplicate sources cannot qualify. Legacy proof versions keep their original validators and verdicts.

Update the actual installed build support and runtime guide together. Keep the nine public entrypoints and the existing native launcher. No interception, decryption, host patch, alternative launcher, new decision authority or shared installation change is authorized by this design.
