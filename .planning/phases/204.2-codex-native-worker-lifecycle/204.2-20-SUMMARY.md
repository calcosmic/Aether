## What changed

`nativeCodeModeCommands` now uses a small lexical decoder for command objects instead of globally rewriting object keys and feeding JavaScript-shaped text to a JSON map. Single- and double-quoted literals preserve shell quotes, escaped apostrophes/backslashes, whitespace, Unicode and valid surrogate pairs. Allowed fields are exactly `cmd`, `workdir`, `max_output_tokens` and `yield_time_ms`; the latter two require unsigned decimal integer literals.

Duplicate keys, including differently escaped spellings of the same key, are rejected. Expressions, template literals, object spread, computed properties, unknown keys, nonliteral limits, unsupported calls, extra statements, mismatched printed variables, malformed escapes and unpaired Unicode surrogates reject. Parent edits, required checks and arbitrary interpreter commands remain refused. Existing same-thread/turn/cwd/argv/result and unique-event gates remain in force; no shell or interpreter was generally authorized, and no mandatory Watcher floor was added.

The unchanged `cmd/codex_native_gap_context_test.go` was included in the scoped inventory and verification.
