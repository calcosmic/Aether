<objective>
`/ant-memory-details` promises "wisdom, pending promotions, and recent failures" and delivers a row of bare counts as raw JSON, because the command is a plain alias of the metrics command with no renderer. The status screen has the opposite problem: it ranks instincts by usefulness but labels the list "Recent Instincts", so the heading lies about the data underneath it. This plan gives the drill-down back its content and makes the status label true.

Purpose: FEED-06 — the owner can see what the colony has learned.
Output: a rendered drill-down, a real "last changed" timestamp for the Queen file, and an honest status heading.
</objective>
