<objective>
A lesson strong enough to be worth sharing across projects currently waits for the project to be formally finished before it leaves. A project that is never formally finished — which is most of them — contributes nothing, ever. This plan promotes strong lessons at the end of each check instead, under the same on/off switch the finish path already honours. It then goes through CLAUDE.md and makes every sentence about the learning loop either true and test-named, or deleted.

Purpose: FEED-05, plus FEED-04's requirement that the documented claims are backed by tests.
Output: `cmd/phase_end_hive.go`, a corrected CLAUDE.md, and a guard that stops the corrections rotting.
</objective>
