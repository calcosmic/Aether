<objective>
Close the Phase 165 blocker (Truth 10 / review CR-01) and the WR-05 ordering
warning, both of which live in `init.md`.

`.claude/commands/ant/init.md:257` (byte-identical in `.opencode/commands/ant/init.md:257`
and the flat mirror `.claude/commands/ant-init.md:257`) currently reads:

> Promoted items become todos: append `[shelf:{category}] {text}` to `active_todos`
> in the session file or colony state.

That is a hand-write instruction to protected state. It contradicts the same
file's `<read_only>` block, the guardrail in `.aether/commands/init.yaml`, and
165-05-PLAN.md Task 2's own CRITICAL D-2 fence. It is the Frankenstein-state
corruption class this project already suffered once.

Independent investigation confirms it is also **futile as written**, which
decides the fix:

1. The Shelf Backlog stage runs *before* colony state exists — `aether init`
   has not run yet, so at that moment there is no session or colony state file
   for this colony to append to.
2. `session.ActiveTodos` is unconditionally recomputed from colony-state phase
   tasks on every session refresh (`cmd/session_cmds.go:237` and
   `cmd/recovery_snapshot.go:132`), so any hand-appended entry is erased on the
   next `aether` command.
3. `shelfEntryToTodo` in `cmd/shelf_init.go:154` produces exactly the promised
   string and has zero call sites. `promoteShelfEntry` only flips shelf status.

So this plan does not merely delete the sentence — deleting alone would silently
drop the "promoted items become todos" promise. It routes the write through the
runtime (the verification's own sanctioned alternative), gives `shelfEntryToTodo`
its first call site, makes the seeded todo survive session refresh, and then
fixes the wrapper prose and fences the phrasing with a test.

Purpose: a promise the wrapper makes to the user becomes a runtime behavior with
a test that fails when it is unmet, instead of an instruction that corrupts state.
Output: runtime shelf-to-todo wiring, a regression fence in init.md's ceremony
test, and corrected init.md prose on all three surfaces plus its YAML source.
</objective>
