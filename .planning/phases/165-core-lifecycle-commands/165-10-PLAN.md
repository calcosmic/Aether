<objective>
Close the wrapper half of the Phase 165 blocker (Truth 8 / review CR-01) and fix
the stale test doc comment (review WR-06).

Plan 165-09 moved shelf promotion inside `aether init`. This plan makes the three
`init.md` surfaces use it, so the hazard becomes unrepresentable in the prose:
after this change there is no shelf-mutating command anywhere in the wrapper for
an executor to place before the consent gate.

The Shelf Backlog stage stops calling `aether shelf-promote-batch` /
`aether shelf-dismiss-batch` and instead collects the user's chosen IDs as
cross-stage state. The Approval stage passes them to the same `aether init` call
that creates the colony, using the same `refined_goal` — so a cancel writes
nothing, a failed init writes nothing, and a goal revision cannot orphan an
entry, because the promotion and the colony share one goal value inside one
runtime call.

The verification's third `missing:` item — "update init.md's `<failure_modes>`
text to match actual behavior, or fix the ordering so the existing claim is true
again" — is satisfied the second way: the claim becomes true, and the text gains
an explicit mention of the shelf so a future reader cannot repeat the omission.

Purpose: the ordering hazard is removed at the source rather than documented
around, and a test fails if either batch command ever returns to the wrapper.
Output: corrected prose on all three surfaces, its YAML and Codex guide sources
in lockstep, and a ceremony-test fence proven RED before the fix.
</objective>
